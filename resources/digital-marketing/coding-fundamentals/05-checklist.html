Coding Environment Setup

Set up everything you need to start coding — step by step

Step 1: Code Editor

  • Install Visual Studio Code
    Download from code.visualstudio.com. Available for Windows, Mac, and Linux. Free forever.
  • Set up VS Code extensions
    Install: Live Server, Prettier, ESLint, HTML CSS Support, Auto Rename Tag.
  • Configure auto-save and formatting
    Enable "Auto Save" in settings. Set Prettier as default formatter.

Step 2: Browser & DevTools

  • Install Google Chrome (if not already)
    Best developer tools built-in. Download from google.com/chrome.
  • Learn to open DevTools
    Right-click → Inspect, or F12. Bookmark the Elements tab.
  • Test the Console
    Open Console tab in DevTools. Type: alert("Hello!") and press Enter.

Step 3: Git Version Control

  • Install Git
    Download from git-scm.com. Follow the default installation options.
  • Verify installation
    Open terminal and type: git --version. You should see a version number.
  • Create a GitHub account
    Sign up at github.com. This is where you'll store your code projects online.

Step 4: Node.js (Optional but Useful)

  • Install Node.js LTS version
    Download from nodejs.org. Choose LTS (Long Term Support) version.
  • Verify Node and npm
    Type: node --version and npm --version in terminal.

Step 5: Terminal Basics

  • Learn essential terminal commands
    cd (change directory), ls/dir (list files), pwd (current path), clear (clear screen).
  • Use VS Code's built-in terminal
    View → Terminal, or Ctrl + `. Works on Windows (PowerShell) and Mac (zsh).

Step 6: First Project Folder

  • Create project folder structure
    Create a folder called "my-first-website" with subfolders: css/, js/, images/.
  • Create your first HTML file
    Inside the folder, create index.html with basic HTML boilerplate.
  • Open in browser using Live Server
    Right-click index.html → "Open with Live Server" in VS Code.

💡 Your Folder Should Look Like This

my-first-website/
├── index.html
├── css/
│ └── style.css
├── js/
│ └── main.js
└── images/
