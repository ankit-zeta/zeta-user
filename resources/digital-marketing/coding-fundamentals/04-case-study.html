How Websites Are Built

Deconstructing a real website's code structure layer by layer

The Three Layers

Every website is built from three core technologies working together. Think of it like a house: HTML is the frame, CSS is the paint and decor, and JavaScript is the electricity.

Layer 1

HTML — The Structure

HTML defines what content exists on the page: headings, paragraphs, images, links, forms. It's the skeleton that everything else hangs on.

<!DOCTYPE html> <html lang="en"> <head> <title>My Business Site</title> </head> <body> <header> <nav> <a href="/">Home</a> <a href="/about">About</a> </nav> </header> <main> <h1>Welcome to Our Business</h1> <p>We help customers solve problems.</p> <img src="hero.jpg" alt="Our team"> </main> <footer> <p>© 2026 My Business</p> </footer> </body> </html>
Layer 2

CSS — The Presentation

CSS controls how everything looks: colors, fonts, spacing, layout, animations. It makes ugly HTML beautiful and responsive across devices.

/* Reset default browser styles */ * { margin: 0; padding: 0; box-sizing: border-box; } /* Typography */ body { font-family: 'Inter', sans-serif; line-height: 1.6; } /* Layout with Flexbox */ header nav { display: flex; gap: 20px; } /* Responsive design */ @media (max-width: 768px) { header nav { flex-direction: column; } } /* Visual styling */ h1 { font-size: 2.5rem; color: #176B4D; } p { color: #4b5563; margin-bottom: 1rem; }
Layer 3

JavaScript — The Interactivity

JavaScript makes things happen: form validation, animations, API calls, dynamic content updates, interactive menus, and more.

// Mobile menu toggle const menuBtn = document.querySelector('.menu-toggle'); const nav = document.querySelector('nav'); menuBtn.addEventListener('click', () => { nav.classList.toggle('active'); }); // Form validation const form = document.querySelector('form'); form.addEventListener('submit', (e) => { const email = form.querySelector('[type=email]'); if (!email.value.includes('@')) { e.preventDefault(); alert('Please enter a valid email'); } });

Behind the Scenes: Backend

Beyond the browser, websites need server-side code for data storage, user accounts, and dynamic content.

Frontend (Client-Side)

Runs in the user's browser. HTML, CSS, JavaScript. Visible and interactive. Handles UI/UX.

Backend (Server-Side)

Runs on a server. Python, Node.js, PHP, databases. Hidden from users. Handles data & logic.

Example flow: User clicks "Add to Cart" → JavaScript sends request → Backend processes it → Database stores item → Server sends response → JavaScript updates cart count.

What Makes It a "Website"?

  • Domain name — zetagrow.in (the address people type)
  • Hosting — Where files live on the internet (server/computer always online)
  • DNS — Translates domain name to server IP address
  • SSL Certificate — Enables HTTPS (the lock icon, secure connection)
  • Web Server — Apache, Nginx, or cloud (sends files to browsers on request)

💡 Try It Yourself

Right-click any website → "View Page Source" to see the HTML. Right-click → "Inspect" to see CSS and JavaScript. This is how every developer learns by studying real code.
