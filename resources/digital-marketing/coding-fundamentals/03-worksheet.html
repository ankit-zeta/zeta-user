Coding Fundamentals

Practice Exercises

10 hands-on coding exercises to build your skills from the ground up

1
Variables & Operators
Declare variables and perform basic math operations.
  • Create variables for your name, age, and favorite number
  • Calculate: if someone is born in 2000, what is their age in 2026?
  • Practice: multiply two numbers, find the remainder (%), and use string concatenation
Hint: Use console.log() in JavaScript or print() in Python to see results.
2
Conditional Logic
Write programs that make decisions based on conditions.
  • Write a program that takes a number and prints "Positive", "Negative", or "Zero"
  • Create a grade calculator: 90+ = A, 80-89 = B, 70-79 = C, below 70 = F
  • Bonus: Handle invalid input (negative numbers, numbers above 100)
Hint: Use if/else if/else chains. Remember: elif in Python, else if in JavaScript.
3
Loops
Master repetition with for and while loops.
  • Print numbers 1-10 using a for loop
  • Print only even numbers from 1-20
  • Calculate the sum of numbers 1-100
Hint: In JavaScript: for (let i = 1; i <= 10; i++). In Python: for i in range(1, 11).
4
Functions
Create reusable blocks of code.
  • Write a function that takes a name and returns "Hello, [name]!"
  • Create a function that calculates the area of a rectangle (width × height)
  • Build a temperature converter: Celsius to Fahrenheit and back
Hint: Use return to send values back from functions, not just console.log/print.
5
Arrays / Lists
Work with collections of data.
  • Create an array of 5 fruits and print each one
  • Add a new fruit, remove the second one, and find the array length
  • Write a function that finds the largest number in an array
Hint: JavaScript: push/pop/splice. Python: append/pop/remove.
6
Objects / Dictionaries
Store structured data with key-value pairs.
  • Create an object representing yourself (name, age, skills array, isStudent boolean)
  • Add a new property and update an existing one
  • Write a function that takes an object and prints a formatted profile
Hint: JavaScript: dot notation (obj.key) or bracket notation (obj["key"]). Python: dict["key"].
7
String Manipulation
Transform and analyze text data.
  • Convert a string to uppercase and lowercase
  • Check if a string contains a specific word
  • Count the number of vowels in a string
Hint: JavaScript: toUpperCase(), includes(), split(""). Python: upper(), "x" in string, list comprehension.
8
Debugging Practice
Find and fix errors in broken code.
  • The code below has 3 bugs — find and fix them:
  • function add(a, b)
      return a + b
    console.log(add(5))
  • Common errors: missing return, wrong number of arguments, typos
Hint: Read error messages carefully. They often tell you exactly what's wrong and which line.
9
Mini-Project: Calculator
Build a simple calculator using functions.
  • Create functions: add, subtract, multiply, divide
  • Write a calculate function that takes two numbers and an operator
  • Handle division by zero with an error message
Hint: Use if/else to check which operator was passed, then call the right function.
10
Mini-Project: To-Do List
Build a command-line to-do list manager.
  • Store tasks in an array
  • Create functions: addTask, removeTask, listTasks, markComplete
  • Bonus: save/load tasks from a file (Node.js fs or Python file I/O)
Hint: Start simple with just the add and list functions, then add features one at a time.

💡 How to Use This Worksheet

1. Open your code editor (VS Code) and a browser console or terminal
2. Complete each exercise in order — they build on each other
3. Type the code yourself — don't copy-paste
4. Break things on purpose to understand what errors look like
5. Move to the next exercise once you're comfortable
