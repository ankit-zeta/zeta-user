Analytics Implementation Case Study

How a business went from zero tracking to data-driven decisions: setup, event tracking, conversion optimization, reporting

Background: "GrowthMarketing Co."

B2B Marketing Agency — 15 employees, $2.4M ARR

Before: GA3 (Universal Analytics) with basic page views only. No event tracking, no conversions, no UTM governance. Marketing decisions based on gut feel. 40% of ad spend wasted on non-converting channels.

Goal: Full-funnel visibility from impression → lead → customer. Data-driven budget allocation. Monthly reporting to leadership.

Phase 1: Foundation (Weeks 1-2)

GA4 Setup & Governance

Property Structure

• 1 Property: "GrowthMarketing Production"
• Data Stream: Web (primary), iOS App, Android App
• Data Retention: 14 months → 26 months
• BigQuery Export: Daily (for historical analysis)

Enhanced Measurement

• Enabled: Scroll, Video, Download, Form, Search
• Disabled: Outbound Clicks (too noisy)
• Custom: Form submit → generate_lead event

Internal Traffic Filter

• Office IP ranges (3 locations)
• Employee home IPs (voluntary)
• Staging/Dev subdomains excluded
• Test traffic parameter: ?gtm_debug=x

UTM Governance Doc

• Shared Google Sheet: "UTM Master"
• Columns: Channel, Source, Medium, Campaign Pattern, Content, Owner
• Dropdown validation for Source/Medium
• Quarterly audit calendar invite

Phase 2: Event Architecture (Weeks 3-4)

Custom Event Implementation via GTM

Lead Funnel Events

• form_start (Enhanced Measurement)
• form_submit → generate_lead (conversion)
• Parameters: form_type, lead_source, page_location
• CTAs tracked: button_click (header, hero, footer, sidebar)

Content Engagement

• blog_read (scroll 75% + 30s dwell)
• case_study_view (custom event)
• whitepaper_download (file_download + custom)
• webinar_register / webinar_attend

Account Events

• sign_up (method: email/google/sso, plan_type)
• login (method, user_type)
• trial_started (plan_type, source)
• upgrade_initiated / upgrade_completed

Custom Dimensions (25 registered)

• form_type, lead_source, button_location
• plan_type, user_type, content_category
• author, content_length, topic_cluster

Phase 3: Conversion & Attribution (Weeks 5-6)

Conversion Definitions & Offline Import

GA4 Conversions

• generate_lead (Once per session)
• sign_up (Once per event)
• purchase (Once per event, dynamic value)
• begin_checkout (Once per session, funnel)

Attribution Model

• Data-Driven (default, 600+ conversions)
• Lookback: 30 days (sales cycle ~45 days)
• Model Comparison: DDA vs Last Click weekly
• Cross-channel in Advertising section

Offline Conversion Import

• CRM (HubSpot) → GA4 via Measurement Protocol
• Events: qualified_lead, opportunity_created, deal_won
• GCLID captured on form submit (hidden field)
• Daily automated sync via Cloud Function

Enhanced Conversions (Ads)

• Email + Phone hashed sent with conversions
• User-provided data from forms
• Improved match rate: 72% → 94%

Phase 4: Reporting & Action (Weeks 7-8)

Dashboards & Optimization Loop

Looker Studio Dashboards

• Executive: 8 KPIs (Users, Engagement, Leads, Revenue, ROAS, CAC, LTV, Churn)
• Marketing: Channel performance, Campaign ROI, Funnel visualization
• Content: Top posts, Engagement by topic, Author performance
• Auto-emailed Monday 8am to leadership

Monthly Optimization Cycle

• Week 1: Data review → identify waste
• Week 2: Budget reallocation (cut bottom 20%)
• Week 3: Creative/landing page tests launch
• Week 4: Results review → document learnings

Key Insights Discovered

• Organic Social → 3x higher LTV than Paid Social
• Email nurture → 40% of deals influenced (not last-click)
• Long-form content (>3000 words) → 5x more leads
• Tuesday/Thursday 10am → peak B2B engagement

Budget Reallocation Results

• Cut: Display prospecting (-$8K/mo)
• Cut: Broad match generic keywords (-$5K/mo)
• Increase: LinkedIn Ads retargeting (+$6K/mo)
• Increase: Email automation (+$2K/mo)
• Net: $180K annual savings, revenue +15%

Implementation Checklist Used

Weekly QA Routine

  • ☐ GA4 DebugView: Test all custom events fire correctly
  • ☐ GTM Preview: Verify tags firing on key pages
  • ☐ Realtime Report: Confirm live data flowing
  • ☐ Conversion Count: Match GA4 ↔ CRM (within 5%)
  • ☐ UTM Audit: Filter Traffic Acquisition by source → check naming
  • ☐ BigQuery: Verify daily export completed
  • ☐ Looker Studio: Dashboard refresh successful

Lessons Learned

What Worked

  • Measurement Plan First: Documented events, parameters, conversions BEFORE coding. Saved 3 weeks of rework.
  • UTM Governance Sheet: Single source of truth. Eliminated "utm_source=FB" vs "facebook" chaos.
  • Offline Import: Connecting CRM → GA4 unlocked true attribution. Marketing could finally prove influence.
  • BigQuery Export: Enabled cohort analysis impossible in GA4 UI (e.g., "LTV by first content topic").

What Didn't Work

  • Too Many Custom Events Initially: 47 events → noise. Consolidated to 22 core events.
  • No User ID at Launch: Added Month 3. Lost 2 months of cross-device data.
  • GA4 UI Limitations: Funnel exploration limited. Moved complex analysis to BigQuery/Looker.

Key Insight

Analytics is not a "set and forget" project. It's a product: plan → build → measure → iterate. The companies that win treat their data stack like a product with a roadmap, not a one-time implementation.
