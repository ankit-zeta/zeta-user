Data Interpretation Cheat Sheet

Reading acquisition reports, understanding engagement metrics, funnel drop-off analysis, cohort analysis basics, anomaly detection

Acquisition Reports — What to Look For

Traffic Acquisition (Session-scoped)

Where NEW sessions come from. Use for: Channel mix, campaign performance, new user acquisition cost. Compare: Sessions, Engaged sessions, Engagement rate, Conversions.

User Acquisition (User-scoped)

Where NEW USERS first came from. Use for: LTV by channel, long-term channel value, cohort analysis. First user source/medium/campaign never changes.

Channel Grouping Issues

"Unassigned" = missing UTM or cross-domain gap. "(direct)" = bookmarks, typed, dark social, email clients. "Cross-network" = Performance Max / Smart Shopping where Google hides network.

Benchmark Flags

Organic Search > 40% = healthy SEO. Paid Search > 30% = heavy paid dependence. Email < 5% = underutilized owned channel. Referral < 10% = weak partnerships/backlinks.

Engagement Metrics Deep Dive

Engagement Rate vs Bounce Rate

Engagement Rate = Engaged Sessions / Sessions. Engaged = >10s OR 1+ conversion OR 2+ pageviews. Inverse of old Bounce Rate. Higher = better. Target: >50% (content), >60% (product), >40% (blog).

Average Engagement Time

Total engagement time / Active Users. Only counts when tab is VISIBLE (not background). More accurate than UA's Avg Session Duration. Segment by page: Blog > 2min, Product > 1min, Landing < 30s.

Events per Session

Total Events / Sessions. Measures interaction depth. E-commerce: >5 = healthy. Content: >3 = good. Low (<2) = tracking gaps or poor UX.

Pages/Screens per Session

Pageviews / Sessions. Navigation depth. High + low engagement time = confused users. Low + high engagement time = single-page app or great landing page.

Funnel Drop-Off Analysis

Identify Biggest Leaks

Funnel Exploration → Look for largest % drop between steps. Typical e-commerce: View Item (100%) → Add to Cart (15%) → Begin Checkout (8%) → Purchase (3%). Biggest leak: View → Cart (85% drop).

Segment Funnel by Dimension

Break down funnel: Device (mobile vs desktop), Source (paid vs organic), New vs Returning, Country. Mobile often 2x drop-off at checkout. Paid traffic drops earlier than organic.

Time Lag Analysis

Advertising → Conversion Paths → Time Lag. How many days from first touch to conversion? B2B: 30-60 days. E-com: 1-3 days. If time lag increasing → nurture sequence needed.

Path Exploration

Path Exploration → Start: Landing Page → End: Purchase. Look for: Loops (users stuck), Dead ends (404/exit), Unexpected detours (support pages before purchase = friction).

Cohort Analysis Basics

Cohort Definition

Group of users sharing a characteristic in a timeframe. Default: Acquisition cohort (first session week). Retention = % of cohort active in subsequent weeks.

Retention Curve Shapes

Flat (good) = product-market fit. Steep drop week 1 = onboarding failure. Smile curve (dip then rise) = habit formation. Cliff at week 4 = trial expiry.

Cohort Breakdowns

By: First user medium (organic vs paid cohorts), First user campaign, Device, Country, Content topic (first article read). Paid cohorts often retain worse than organic.

Predictive Cohorts (GA4)

Likely 7-day purchasers, Likely 7-day churners, Predicted 28-day revenue top 10%. Requires 1000+ purchasers/churners in 28 days. Export to Ads for targeting.

Anomaly Detection

Traffic Spikes

Check: Bot traffic (low engagement, high bounce, single page), Referral spam (unknown domains), Campaign launch (expected), Viral content (check social), Tracking duplicate (double fire).

Traffic Drops

Check: GA4/GTM implementation broken, Site down / redirect loop, Google algorithm update (organic), Ad disapproval / budget exhausted (paid), Seasonal (holidays, weekends), Cookie consent changes.

Conversion Rate Drops

Check: Landing page changed, Form broken, Payment gateway down, Offer expired, Audience quality shifted (broad match expansion), Attribution window change, Consent mode blocking.

Revenue Discrepancies

GA4 vs Backend: GA4 misses offline, duplicates, refunds not deducted, currency conversion, test orders included. Reconcile weekly. Tolerance: ±5%.

Quick Diagnostic Questions

"Why did conversions drop?"

1. Check Realtime → any firing? 2. Check Traffic Acquisition → which channel dropped? 3. Check Funnel → which step dropped? 4. Check Events → specific event broken? 5. Check source: site change, ad change, seasonality?

"Why is engagement rate low?"

1. Landing page mismatch (ad promises X, page delivers Y) 2. Slow load (LCP > 4s) 3. Poor mobile UX 4. Wrong audience (broad targeting) 5. Content not scannable 6. Tracking missing (scroll, video not firing)

"Why is ROAS declining?"

1. CPA up (check: CPC up, CVR down) 2. AOV down (check: discounting, product mix) 3. Attribution loss (iOS 14, consent mode) 4. Creative fatigue (frequency > 3) 5. Audience saturation (reach > 80%)

"Why don't GA4 and Ads match?"

1. Attribution model diff (Ads: last click / DDA; GA4: DDA) 2. Conversion window diff (Ads: 30d click; GA4: 30d DDA) 3. Cross-device (Ads better) 4. View-through (Ads counts; GA4 doesn't) 5. Offline import missing in GA4

💡 Pro Tip

Bookmark: GA4 Dimensions & Metrics Explorer (ga-dev-tools.web.app/ga4/dimensions-metrics-explorer). When in doubt, check if the dimension/metric exists and what scope it has (user/session/event).
