Analytics & Tracking Setup

Tracking Implementation Checklist

GA4 installed, events configured, conversions marked, UTM builder ready, dashboard created, alerts set, monthly review scheduled

GA4 Property Setup

  • GA4 property created
    Correct timezone, currency, data retention (26 months recommended)
  • Data stream configured
    Web stream URL correct; Enhanced Measurement enabled (review each)
  • Measurement ID deployed
    G-XXXXXXXXXX in gtag.js or GTM on all pages
  • Cross-domain tracking
    All user-traversed domains added in stream settings
  • Internal traffic filters
    Office IPs, staging domains, developer traffic excluded
  • Google Signals enabled
    Demographics, cross-device, remarketing audiences
  • BigQuery export linked
    Daily export for historical analysis; streaming for real-time

Event Configuration

  • Naming convention documented
    snake_case, past tense, object_action (view_item not item_view)
  • Standard events firing
    page_view, scroll, click, video_play, file_download, form_start, form_submit, search
  • Custom events implemented
    generate_lead, sign_up, purchase, add_to_cart, begin_checkout, etc. via GTM
  • Event parameters populated
    page_location, item_id, value, currency, form_id, button_location, etc.
  • Custom dimensions registered
    Event-scoped (max 50): form_type, lead_source, button_location, plan_type, user_type...
  • User-scoped dimensions registered
    user_id, customer_tier, lifetime_value_bucket (max 25)
  • Data layer structure defined
    window.dataLayer.push({event: 'name', param: 'value'}); consistent across site

Conversion Setup

  • Key events marked as conversions
    Admin → Events → Mark as conversion: purchase, generate_lead, sign_up, begin_checkout
  • Count method set correctly
    Once per session (leads) vs Once per event (purchases)
  • Conversion values configured
    Dynamic (event value) for purchase; static estimated value for leads
  • Attribution model selected
    Data-Driven (default) — requires 300 conv/30d; else Last Click
  • Lookback window configured
    30 days default; adjust to match sales cycle (max 90 days)

UTM & Campaign Tracking

  • UTM Master Sheet created
    Shared Google Sheet with validation: Channel, Source, Medium, Campaign Pattern, Content, Owner
  • Naming conventions enforced
    Lowercase, underscores only, no spaces/special chars
  • URL Builder tool bookmarked
    ga-dev-tools.web.app/campaign-url-builder for every link
  • Auto-tagging enabled (Google Ads)
    Settings → Account Settings → Auto-tagging: ON
  • Consent Mode v2 (EU/UK)
    CMP integrated; ad_storage, analytics_storage consent signals firing

E-Commerce & Monetization

  • Ecommerce events implemented
    view_item, add_to_cart, remove_from_cart, begin_checkout, add_payment_info, purchase, refund
  • Items array populated correctly
    item_id, item_name, price, quantity, item_brand, item_category, item_variant
  • Transaction IDs unique
    String format; prevents duplicate purchase counting
  • Currency codes ISO 4217
    USD, EUR, GBP — required for monetary events
  • Promotion tracking
    view_promotion, select_promotion with promotion_id, creative_name, creative_slot

Debugging & Validation

  • GA Debugger extension installed
    Chrome extension; logs all hits to console with parameters
  • GTM Preview mode tested
    All tags firing correctly; variable values as expected
  • GA4 DebugView verified
    Admin → DebugView; test device shows event stream
  • Realtime report confirmed
    Active users, Events (last 30 min), Conversions firing live
  • Conversion count matches backend
    GA4 conversions ↔ CRM/orders within 5% tolerance

Reporting & Monitoring

  • Executive dashboard created
    Looker Studio: 8-12 KPIs (Users, Engagement Rate, Leads, Revenue, ROAS, CAC, LTV, Churn)
  • Marketing dashboard created
    Channel performance, Campaign ROI, Funnel visualization
  • Scheduled email delivery
    Monday 8am to stakeholders; PDF + live link
  • Custom alerts configured
    GA4 Admin → Custom Alerts: Traffic drop >50%, Conversion spike, Revenue anomaly
  • Monthly review calendar blocked
    First Monday: Data review → insights → budget reallocation → test planning

💡 Pro Tip

Run this checklist monthly. Score each section 1-5. Focus on lowest scores. Track progress over quarters. Analytics is a product — iterate on it like one.
