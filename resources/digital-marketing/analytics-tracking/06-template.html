Event Naming Convention Document

Standardized Event Taxonomy

NAMING RULES: - Format: snake_case (lowercase, underscores) - Tense: Past tense (completed action) - Structure: object_action (view_item, add_to_cart, form_submit) - Max 40 characters, max 25 parameters per event - Max 500 distinct event names per property NAVIGATION & ENGAGEMENT: page_view (auto) — page_location, page_title, page_referrer scroll (auto) — page_location, percent_scrolled video_play (auto) — video_url, video_title, video_provider, progress file_download (auto) — file_extension, file_name, link_url search (auto) — search_term, results_count user_engagement (auto) — engagement_time_msec CTA & INTERACTION: button_click — button_text, button_location, destination_url, button_type link_click — link_url, link_text, link_location, is_external menu_click — menu_item, menu_location, menu_type tab_click — tab_name, tab_container accordion_toggle — accordion_title, is_expanded tooltip_view — tooltip_text, trigger_element FORM & LEAD FUNNEL: form_start — form_id, form_name, form_type, form_location form_submit — form_id, form_name, form_type, lead_source, page_location generate_lead (conversion) — form_type, lead_source, value (estimated), currency contact_request — request_type, department, urgency ACCOUNT & AUTH: sign_up — method (email/google/sso/magic_link), plan_type, user_type, source login — method, user_type, remember_me logout — session_duration, user_type password_reset_request — method password_reset_complete — method E-COMMERCE: view_item — item_id, item_name, price, quantity, item_brand, item_category, item_variant select_item — item_id, item_name, price, quantity, index, list_name add_to_cart — item_id, item_name, price, quantity, cart_value, currency remove_from_cart — item_id, item_name, price, quantity, cart_value view_cart — cart_value, currency, item_count begin_checkout — value, currency, items[], coupon, shipping_tier add_payment_info — payment_type (card/paypal/apple_pay/google_pay), shipping_cost apply_coupon — coupon_code, discount_amount, discount_type CONTENT & MARKETING: blog_read — article_id, article_title, author, category, read_time, scroll_depth whitepaper_download — document_id, document_title, topic, gated (true/false) webinar_register — webinar_id, webinar_title, date, source webinar_attend — webinar_id, duration_minutes, engaged_actions case_study_view — Custom Report Templates (GA4 Explore)

Report 1: Marketing Channel Performance

TECHNIQUE: Free Form DIMENSIONS: Session default channel group, Session source/medium, Session campaign METRICS: Sessions, Engaged sessions, Engagement rate, Conversions, Total revenue, ROAS FILTERS: Session medium != (referral, organic) — focus on paid VISUALIZATION: Table + Bar chart (Sessions by channel) SEGMENTS: New users vs Returning users

Report 2: Conversion Funnel

TECHNIQUE: Funnel Exploration STEPS: 1. session_start (or page_view landing page) 2. view_item (or key content view) 3. add_to_cart (or begin_checkout / form_start) 4. begin_checkout (or form_submit) 5. purchase (or generate_lead) VISUALIZATION: Funnel chart + Abandonment table BREAKDOWN: Device category, Country, Traffic source MAKE OPEN FUNNEL: No (closed funnel)

Report 3: Content Performance

TECHNIQUE: Free Form DIMENSIONS: Page path + query string, Page title, Content group (custom dim), Author (custom dim) METRICS: Views, Active users, Average engagement time, Conversions, Event count (blog_read) FILTERS: Page path contains /blog/ OR /resources/ OR /case-studies/ VISUALIZATION: Table (sort by Views desc) + Scatter plot (Views vs Engagement time) SEGMENTS: Organic traffic, Email traffic, Social traffic

Report 4: E-Commerce Product Performance

TECHNIQUE: Free Form DIMENSIONS: Item name, Item brand, Item category, Item variant METRICS: Item views, Add to carts, Cart-to-view rate, Purchases, Purchase-to-view rate, Item revenue, Item purchase quantity VISUALIZATION: Table + Bar chart (Revenue by category) CALCULATED METRICS: Cart-to-view = Add to carts / Item views; Purchase-to-view = Purchases / Item views

Report 5: User Journey / Path Analysis

TECHNIQUE: Path Exploration STARTING POINT: page_view (homepage) OR session_start ENDING POINT: purchase OR generate_lead OR sign_up STEP LIMIT: 10 VIEW UNIQUE NODES: On EXPAND NODES: Click to expand top 5 events per step USE CASE: Identify drop-off points, common paths to conversion, loops

Report 6: Cohort Retention

TECHNIQUE: Cohort Exploration COHORT GRANULARITY: Weekly COHORT DEFINITION: First session date (acquisition cohort) RETURN CRITERIA: Any event (or specific: session_start, purchase) METRIC: Active users (retention rate) BREAKDOWN: First user medium, First user campaign, Device category VISUALIZATION: Heatmap (cohort vs week) + Line chart (retention curves)
