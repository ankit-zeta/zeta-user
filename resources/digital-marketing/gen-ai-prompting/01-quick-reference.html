Prompt Power Words

Accuracy Boosters

Be specific, factual, precise, accurate, cite sources, step-by-step, think carefully, double-check

Creativity Triggers

Think outside the box, unconventional, creative, surprising, bold, innovative, lateral thinking

Quality Controls

Expert level, senior, professional, best practices, industry standard, thorough, comprehensive

Format Instructions

As a table, bullet points, numbered list, JSON, markdown, code block, CSV, comparison format

Prompt Templates by Use Case

Content Writing

"Act as a [role]. Write a [type] about [topic]. Target audience: [who]. Tone: [tone]. Length: [words]. Include: [specific requirements]."

Email Campaign

"Write [number] email subject lines for [product/offer]. Audience: [segment]. Goal: [open/click/conversion]. Tone: [urgent/curious/value]."

Social Media

"Create [number] [platform] posts about [topic]. Include: hook, value, CTA. Tone: [casual/professional]. Hashtags: [relevant ones]."

Ad Copy

"Write [platform] ad copy for [product]. Headline: [max chars]. Primary text: [max chars]. CTA: [action]. Audience: [who]. Benefit: [main value]."

Data Analysis

"Analyze this data: [paste data]. Find patterns, trends, outliers. Explain in plain English. Suggest 3 actionable insights."

Code Review

"Review this code for: bugs, performance, security, readability. Suggest improvements. Explain each issue clearly."

💡 Pro Tip

The best prompt is a conversation, not a command. Start broad, refine based on output. Use "instead of X, try Y" to iterate. Save your best prompts in a personal library organized by use case.
