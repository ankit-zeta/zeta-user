AI Tools Glossary

Essential terminology for understanding AI models, tools, and capabilities

AI Model Types

LLM (Large Language Model)
Neural network trained on text data. Predicts next token. GPT-4, Claude, Gemini, LLaMA. Powers chatbots, writing, code.
Diffusion Model
Generates images from noise. DALL-E, Stable Diffusion, Midjourney. Text-to-image. Iterative denoising process.
Multimodal Model
Processes text + images + audio. GPT-4o (text+image+audio), Gemini (text+image+video+audio). Understands multiple inputs.
Embedding Model
Converts text to vectors (numbers). For search, clustering, recommendations. OpenAI ada-002, Cohere embed. Semantic similarity.
Fine-tuned Model
Base model trained on domain-specific data. Custom GPTs, LoRA adapters. Better at specific tasks. Expensive to train.
Open Source vs Closed
Open: LLaMA, Mistral, Stable Diffusion. Closed: GPT-4, Claude, DALL-E. Open = customizable. Closed = better quality.

Core Concepts

Token
Unit of text processing. ~4 chars = 1 token. "Hello" = 1 token. "ChatGPT" = 2 tokens. Pricing per 1M tokens.
Context Window
Max tokens model can process at once. GPT-4: 128K. Claude: 200K. Gemini: 1M. Larger = handle longer texts.
Temperature
Randomness (0-1). 0 = deterministic, 1 = creative. Low for facts, high for brainstorming. Affects output diversity.
Hallucination
Model generates false information confidently. Always verify facts. Ask for sources. Cross-reference with known data.
Prompt Engineering
Crafting inputs to get desired outputs. Few-shot, chain-of-thought, persona, format control. Critical skill for AI users.
RAG (Retrieval Augmented Generation)
Retrieves relevant docs before answering. Reduces hallucinations. Used in chatbots with knowledge bases. Vector DB + LLM.
System Prompt
Hidden instruction setting AI behavior. "You are a helpful assistant." Defines persona, rules, constraints. Not visible to users.
Chain of Thought
Step-by-step reasoning. "Let me think through this..." Improves accuracy for complex tasks. Forces logical progression.

AI Tools by Category

Writing: ChatGPT, Claude, Jasper
Long-form, copywriting, emails, articles. Claude best for nuanced writing. GPT-4 best for general tasks.
Image: DALL-E, Midjourney, Stable Diffusion
Text-to-image generation. Midjourney: artistic. DALL-E: realistic. SD: open-source, customizable.
Code: GitHub Copilot, Cursor, Cody
AI pair programming. Autocomplete, debugging, refactoring. Copilot: VS Code. Cursor: AI-native IDE.
Video: Runway, Pika, Sora
Text-to-video, image-to-video. Runway: professional. Pika: fast. Sora: highest quality (limited access).
Audio: ElevenLabs, Descript, Suno
Voice cloning, text-to-speech, music generation. ElevenLabs: realistic voices. Suno: AI music.
Automation: Zapier AI, Make, LangChain
AI workflows, agents, tool integration. Zapier: no-code. LangChain: code-based. Connect AI to any service.

💡 Pro Tip

AI literacy = career advantage. Learn to evaluate outputs, not just generate them. Always verify facts, check for hallucinations, and understand model limitations. Use AI as a tool, not a replacement for thinking.
