AI Prompting Cheat Sheet

Quick reference for prompt techniques, modifiers, and troubleshooting

Prompt Starters by Task

Writing

Act as [role]. Write [type] about [topic]. Audience: [who]. Tone: [tone]. Length: [words]. Include: [requirements].

Analysis

Analyze this [data/text]. Find patterns, trends, outliers. Explain in plain English. Give 3 actionable insights.

Code

Write [language] code that [function]. Use [framework]. Handle edge cases. Include comments. Optimize for [performance/readability].

Research

Research [topic]. Cover: history, current state, future trends, key players, controversies. Cite sources.

Quality Modifiers

Accuracy

Be specific, factual, precise, accurate, double-check, cite sources, step-by-step, think carefully before answering.

Creativity

Think outside the box, unconventional, creative, surprising, bold, innovative, lateral thinking, push boundaries.

Expertise

Expert level, senior, professional, best practices, industry standard, thorough, comprehensive, authoritative.

Format

As a table, bullet points, numbered list, JSON, markdown, code block, comparison format, step-by-step guide.

Troubleshooting Bad Output

Too Generic

Add: specific audience, concrete examples, real data points, industry context, brand voice guidelines.

Wrong Format

Show example: "Format like this: [example]". Specify: bullets vs paragraphs, headers, word count per section.

Off Topic

Reframe: "Focus specifically on [aspect]". Add: "Do NOT include [irrelevant stuff]". Narrow scope.

Hallucinating

Add: "If unsure, say 'I don't know'". "Only use verified facts". "Cite your sources". "Double-check claims".

Model Selection Guide

GPT-4o

Default choice. Fast, multimodal, good at everything. Best for: general tasks, code, analysis, quick drafts.

Claude 3.5 Sonnet

Best for: long-form writing, nuanced analysis, complex instructions, coding. More thoughtful than GPT-4o.

Gemini 1.5 Pro

Best for: very long documents (1M context), video analysis, Google ecosystem integration.

GPT-4o Mini / Haiku

Best for: simple, high-volume tasks. Classification, extraction, summaries. 10-100x cheaper than flagship.

💡 Pro Tip

The "Generate 3 versions" trick: Always ask for multiple options. Pick the best elements from each. Combine into a final version. This gives you variety and lets you cherry-pick the strongest parts.
