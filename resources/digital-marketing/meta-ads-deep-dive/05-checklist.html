Ad Launch Checklist

Complete pre-launch verification: Pixel, audiences, creative, copy, budget, tracking, UTM, landing page

Tracking & Pixel Setup

  • Meta Pixel installed on all pages
    Base code in ; verify with Meta Pixel Helper extension
  • Conversions API (CAPI) connected
    Server-side events via partner integration (Shopify, WP, GTM) or custom
  • Standard events firing correctly
    PageView, ViewContent, AddToCart, InitiateCheckout, Purchase/Lead — test in Events Manager
  • Event Match Quality ≥ 8/10
    Send email, phone, first/last name, city, state, zip, country for best matching
  • AEM configured (8 events max)
    Prioritize events in Events Manager → Aggregated Event Measurement
  • Custom conversions created
    For non-standard events (e.g., "High Value Purchase" > $200)
  • Test purchase/lead completed
    Verify in Events Manager → Test Events; check deduplication

Audience Research & Setup

  • Custom Audiences created
    Website visitors (30/60/180d), purchasers, leads, video viewers, engagers, customer list uploads
  • Lookalike Audiences created
    1%, 2-3%, 5% from best sources (purchasers > leads > visitors)
  • Exclusion audiences applied
    Existing customers (all campaigns), employees, converters (in prospecting)
  • Audience overlap checked
    Tools → Audience Overlap; keep overlap < 15% between prospecting ad sets
  • Advantage+ Audience configured
    Add suggestions (interests/demographics) not hard constraints; let AI optimize

Creative Assets

  • All formats created for each concept
    1:1 (Feed), 9:16 (Stories/Reels), 4:5 (Portrait), 1.91:1 (Link)
  • Video specs met
    ≤4GB, ≤240min, H.264, 30fps max, AAC audio, 1080p min
  • Captions burned into videos
    85% watch without sound; .srt files uploaded for accessibility
  • Brand guidelines followed
    Logo placement, colors, fonts, tone consistent across all assets
  • Text overlay < 20% (legacy rule)
    Meta no longer penalizes, but clean creative performs better
  • Creative named per convention
    Format_Hook_Variation (e.g., VID_Hook1_V1, CAR_Benefit_V2)

Ad Copy & Compliance

  • Primary text: ≤125 chars (truncated)
    Hook in first 80 chars; full text expands on click
  • Headline: ≤40 chars
    Clear benefit or offer; matches landing page
  • Description: ≤30 chars
    Secondary benefit; shows in some placements
  • CTA button selected
    Shop Now, Learn More, Sign Up, Book Now, Contact Us — matches intent
  • No prohibited content
    No before/after (weight loss), misleading claims, crypto, weapons, adult, etc.
  • Special Ad Category declared (if applicable)
    Housing, Employment, Credit, Social Issues — limits targeting
  • Disclosure for partnerships/sponsored
    #ad, #sponsored, Paid Partnership tag for creator content

Budget, Schedule & Bidding

  • Budget type & amount confirmed
    Daily vs Lifetime; amount matches plan; sufficient for learning (50 conv/week/ad set)
  • Bid strategy selected
    Highest Volume (default), Cost Cap, ROAS Goal, Bid Cap — matches goals
  • Campaign dates set
    Start: immediate or scheduled; End: date or ongoing
  • Ad scheduling (if lifetime budget)
    Business hours for B2B; peak hours for DTC; timezone correct
  • CBO vs ABO decision made
    CBO = Meta optimizes; ABO = you control. CBO default for new.

Landing Page & UTM

  • Landing page loads < 3s (mobile)
    PageSpeed Insights > 90; LCP < 2.5s; no layout shift
  • Message match: Ad → LP congruent
    Same headline, offer, imagery, colors; no bait-and-switch
  • UTM parameters on ALL ad URLs
    utm_source=meta&utm_medium=cpc&utm_campaign={{campaign.name}}&utm_content={{ad.name}}
  • Dynamic UTM macros used
    {{campaign.name}}, {{adset.name}}, {{ad.name}} auto-populate in Ads Manager
  • Conversion tracking on thank you page
    Purchase/Lead event fires; deduplication working (Pixel + CAPI)
  • Mobile experience flawless
    Thumb-friendly, no popups, fast checkout, Apple/Google Pay

Safety Guards & Monitoring

  • Automated rules created
    Pause if CPA > 2x target for 3 days; Pause if spend > daily cap; Notify if ROAS < 1.5
  • Spend caps set
    Account spending limit; Campaign spending limit (lifetime)
  • Notification preferences
    Email/push for: disapprovals, spending limits, learning limited, payment issues
  • Creative refresh calendar
    Schedule new creative every 2-3 weeks; batch produce
  • Weekly review calendar blocked
    Monday 9am: Review breakdowns, pause losers, scale winners, plan new tests

💡 Pro Tip

Create a "Launch Checklist" template in Notion/ClickUp. Duplicate for every campaign. Never launch without 100% completion. The 30 minutes saved prevents 30 hours of troubleshooting.
