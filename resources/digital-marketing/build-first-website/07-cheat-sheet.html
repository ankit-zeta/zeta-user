CSS Layout Cheat Sheet

Flexbox properties, CSS Grid patterns, centering techniques, responsive patterns, and common layout solutions

Flexbox Properties

Container Properties

display: flex — enables flexbox
flex-direction: row | row-reverse | column | column-reverse
flex-wrap: nowrap | wrap | wrap-reverse
justify-content: flex-start | center | flex-end | space-between | space-around | space-evenly
align-items: stretch | flex-start | center | flex-end | baseline
align-content: stretch | center | flex-start | flex-end | space-between | space-around
gap: spacing between items

Item Properties

flex-grow: 0 (default) — ability to grow
flex-shrink: 1 (default) — ability to shrink
flex-basis: auto | size — initial size
flex: shorthand for grow shrink basis
align-self: override align-items
order: 0 (default) — visual order

Common Patterns

Holy grail: flex: 1 on main, fixed on aside
Sticky footer: min-height: 100vh; flex-direction: column on body, flex: 1 on main
Card with footer at bottom: flex-direction: column, margin-top: auto on footer

Centering

Horizontal: justify-content: center
Vertical: align-items: center
Both: display: flex; justify-content: center; align-items: center
Single item: margin: auto on item

CSS Grid Properties

Container Properties

display: grid — enables grid
grid-template-columns: track sizes (fr, px, %, auto)
grid-template-rows: track sizes
grid-template-areas: named areas layout
gap / row-gap / column-gap
justify-items / align-items: cell alignment
justify-content / align-content: grid alignment

Item Properties

grid-column-start/end: line numbers or span
grid-row-start/end: line numbers or span
grid-area: shorthand or named area
justify-self / align-self: item alignment
z-index: layering (grid items can overlap)

Track Sizing

fr: fraction of free space (1fr = 1 part)
minmax(min, max): flexible range
auto: content-sized
min-content / max-content
fit-content(limit): clamp to limit
repeat(n, track): repeat pattern

Common Patterns

Holy grail: grid-template: auto 1fr auto / 250px 1fr 200px
Responsive grid: grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))
Card grid: grid-template-columns: repeat(3, 1fr); gap: 24px

Centering Techniques

Flexbox Centering

.center { display: flex; justify-content: center; align-items: center; }
Works for single or multiple items. Best all-around solution.

Grid Centering

.center { display: grid; place-items: center; }
Shortest syntax. place-items = align-items + justify-items.

Absolute + Transform

.center { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }
Parent needs position: relative. Works without flex/grid.

Margin Auto

.center { display: block; margin-left: auto; margin-right: auto; }
Horizontal only. For vertical: needs flex/grid parent or absolute.

Text Centering

.center-text { text-align: center; }
Inline/inline-block content only. Combine with flex/grid for block.

Vertical Text Centering

.v-center { display: flex; align-items: center; height: 100px; }
Or: line-height: 100px on single-line text (fragile).

Responsive Layout Patterns

Stack on Mobile

.grid { display: grid; grid-template-columns: 1fr; }
@media (min-width: 768px) { .grid { grid-template-columns: repeat(3, 1fr); } }

Auto-fit Grid

.grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)); gap: 24px; }
Automatically adjusts columns to container width.

Sidebar Layout

.layout { display: grid; grid-template-columns: 1fr; }
@media (min-width: 1024px) { .layout { grid-template-columns: 280px 1fr; } }

Navbar Responsive

Desktop: display: flex; justify-content: space-between
Mobile: hamburger toggles display: none/block on menu

Card with Image

.card { display: grid; grid-template-rows: auto 1fr auto; }
img { width: 100%; height: 200px; object-fit: cover; }

Media Object

.media { display: flex; gap: 16px; align-items: flex-start; }
.media img { flex-shrink: 0; }
Image stays fixed size, text wraps.

Common Layout Solutions

Sticky Footer

body { min-height: 100vh; display: flex; flex-direction: column; }
main { flex: 1; }
Footer stays at bottom even with little content.

Full-Height Sidebar

.layout { display: grid; grid-template-columns: 250px 1fr; min-height: 100vh; }
.sidebar { position: sticky; top: 0; height: 100vh; }

Equal Height Cards

.grid { display: grid; grid-template-columns: repeat(3, 1fr); }
.card { display: flex; flex-direction: column; }
.card-content { flex: 1; }

Masonry Layout

.masonry { columns: 3; column-gap: 24px; }
.item { break-inside: avoid; margin-bottom: 24px; }
CSS-only masonry (no JS needed).

Split Screen

.split { display: grid; grid-template-columns: 1fr 1fr; min-height: 100vh; }
@media (max-width: 768px) { .split { grid-template-columns: 1fr; } }

Footer with Columns

.footer { display: grid; grid-template-columns: 2fr repeat(3, 1fr); gap: 40px; }
@media (max-width: 640px) { .footer { grid-template-columns: 1fr; } }

💡 Pro Tip

Use repeat(auto-fit, minmax(250px, 1fr)) for most grids — it automatically creates as many columns as fit, never overflows, and handles all screen sizes without media queries.
