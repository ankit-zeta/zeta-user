Website Launch Checklist

Complete pre-launch verification: cross-browser testing, mobile responsiveness, performance, SEO, and accessibility

Cross-Browser Testing

  • Chrome (latest)
    Primary testing browser; check DevTools console for errors
  • Firefox (latest)
    Verify CSS Grid, Flexbox, and form styling
  • Safari (latest)
    Check -webkit prefixes, font rendering, touch events
  • Edge (latest)
    Chromium-based; similar to Chrome but verify anyway
  • Mobile Chrome (Android)
    Test touch interactions, viewport, address bar behavior
  • Mobile Safari (iOS)
    Critical for iOS users; check safe areas, input zoom

Mobile Responsiveness

  • 320px (iPhone SE)
    Smallest common viewport; no horizontal scroll
  • 375px (iPhone 12/13/14)
    Most common mobile width
  • 414px (iPhone Plus/Max)
    Larger mobile screens
  • 768px (iPad portrait)
    Tablet breakpoint; navigation may change
  • 1024px (iPad landscape)
    Desktop-like but touch-enabled
  • 1440px+ (Desktop)
    Full desktop experience; max-width containers
  • Orientation changes
    Rotate device; layout should adapt smoothly
  • Touch targets ≥ 44×44px
    Buttons, links, form inputs meet Apple HIG
  • No horizontal overflow
    Check body, containers, images, tables

Image Optimization

  • WebP format with fallbacks
    with AVIF, WebP, JPEG/PNG fallback
  • Responsive images (srcset)
    Multiple sizes for different device pixel ratios
  • Lazy loading
    loading="lazy" on below-fold images
  • Alt text on all images
    Descriptive, keyword-relevant for SEO/accessibility
  • Optimized file sizes
    Hero < 200KB, thumbnails < 50KB, icons SVG

Meta Tags & SEO

  • Unique title tag (50-60 chars)
    Primary keyword near start; brand at end
  • Meta description (150-160 chars)
    Compelling summary with call-to-action
  • Open Graph tags
    og:title, og:description, og:image, og:url, og:type
  • Twitter Card tags
    twitter:card, twitter:title, twitter:image
  • Canonical URL
    Prevents duplicate content issues
  • Robots meta tag
    index, follow (or noindex for staging)
  • Structured data (JSON-LD)
    Organization, Website, WebPage schemas
  • XML Sitemap
    Generated and submitted to Search Console
  • Robots.txt
    Allows crawling; references sitemap

Performance

  • Lighthouse Performance ≥ 90
    Run in incognito; mobile and desktop
  • LCP < 2.5s
    Largest Contentful Paint — hero image optimization critical
  • INP < 200ms
    Interaction to Next Paint — minimize main thread work
  • CLS < 0.1
    Cumulative Layout Shift — reserve space for images/ads
  • TTFB < 600ms
    Time to First Byte — CDN, caching, server optimization
  • Minified CSS/JS
    Remove whitespace, comments; enable compression
  • Gzip/Brotli compression
    Enabled on server/CDN for text assets
  • Cache headers set
    Static assets: 1 year; HTML: no-cache or short

Accessibility (WCAG 2.1 AA)

  • Semantic HTML structure
    Proper heading hierarchy (h1 → h2 → h3)
  • Color contrast ≥ 4.5:1
    Text vs background; 3:1 for large text
  • Keyboard navigation
    Tab order logical; focus visible on all interactive elements
  • Focus indicators
    Clear :focus-visible styles (not just outline: none)
  • ARIA labels where needed
    Icon buttons, form errors, live regions
  • Form labels associated
  • Skip to main content link
    First focusable element; hidden until focused

Functionality & Security

  • Forms submit correctly
    Validation, success/error states, spam protection
  • Links work (no 404s)
    Internal, external, anchor links all verified
  • HTTPS enforced
    SSL certificate valid; HSTS header set
  • Security headers
    CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy
  • Favicon set (all sizes)
    16×16, 32×32, 180×180, 192×192, 512×512, SVG
  • 404 page custom
    Helpful message, search link, site map
  • Analytics installed
    GA4 + Search Console verified; events firing

💡 Pro Tip

Create a "launch day" checklist duplicate — run through it again 24 hours post-launch to catch anything that broke during deployment.
