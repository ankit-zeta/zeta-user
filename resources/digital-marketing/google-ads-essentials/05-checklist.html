Google Ads Launch Checklist

Account setup, billing, conversion tracking, keyword research, ads, extensions, location targeting, device targeting, schedule

Account Setup & Billing

  • Google Ads account created
    Expert mode (not Smart Campaign); correct timezone & currency (cannot change later)
  • Billing & payments configured
    Payment method added; billing threshold understood; promotional credit applied if eligible
  • Account linking
    Google Analytics 4 (GA4), Google Business Profile, Merchant Center, YouTube, Search Console
  • Manager account (MCC) setup
    If agency/multi-brand: create MCC, link client accounts, set user permissions
  • Auto-tagging enabled
    Settings → Account Settings → Auto-tagging: ON (required for GA4 integration)

Conversion Tracking

  • Google Tag (gtag.js) installed
    On all pages; in ; verify with Tag Assistant / GTM Preview
  • Conversion actions created
    Purchase, Lead, Sign-up, Phone Call, Store Visit — each with correct category, value, count, window
  • Enhanced Conversions enabled
    Hash email/phone/name for better matching; test in Tag Assistant
  • Conversion window set
    30 days (Search), 90 days (consideration), match sales cycle
  • Attribution model selected
    Data-Driven (default, best) — requires 300+ conversions/30d; else Last Click
  • Test conversions firing
    Tag Assistant / GTM Preview → complete test purchase/lead → verify in Conversions → Summary
  • Offline conversion import ready
    CRM → GCLID capture → scheduled upload (daily/weekly) for B2B/long cycles
  • Consent Mode v2 (EU/UK)
    If targeting EEA/UK: CMP integrated, consent_mode parameters firing

Keyword Research Complete

  • Keyword Planner research done
    Seed keywords → search volume, competition, CPC estimates, seasonal trends
  • Competitor keyword analysis
    Tools: Semrush, Ahrefs, SpyFu, or manual Search Terms Report from test campaign
  • Negative keyword list created
    Universal: free, cheap, diy, tutorial, jobs, login, support, complaint, scam, review
  • Keywords grouped by theme/intent
    15-20 per ad group; separate Brand, Non-Brand, Competitor, Generic, Long-tail
  • Match types assigned
    Phrase (default) + Exact (high intent) + Broad (Smart Bidding only) + Negative

Ads Written & Extensions Added

  • RSA: 15 headlines, 4 descriptions per ad group
    Mix: Benefit, Feature, Offer, Social Proof, CTA, Brand, Keyword Insertion; Pin H1 if needed
  • Ad Strength: Good or Excellent
    Fix "Poor" warnings: add unique headlines, include keywords, vary description themes
  • Sitelinks: 4+ per campaign
    Deep links: Categories, Offers, About, Contact, Resources; descriptions added
  • Callouts: 4+ per campaign
    USPs: Free Shipping, 24/7 Support, Money-Back Guarantee, Expert Team
  • Structured Snippets: 2+ headers
    Types, Brands, Models, Services, Categories, Styles, Amenities
  • Call / Location / Price / Promotion
    As applicable: Call (tracking #), Location (GBP linked), Price (services/products), Promotion (seasonal)
  • Image Extensions uploaded
    4-20 images; 1.91:1 and 1:1; high quality; brand consistent

Targeting & Settings

  • Location targeting correct
    Target: People in/regularly in targeted locations (not "interested in")
  • Language targeting matches ad copy
    English ads → English language targeting
  • Audience segments added (Observation)
    Remarketing, In-Market, Affinity, Custom, Demographics — start with Observation
  • Exclusion lists applied
    Customers (all campaigns), Employees, Low-quality, Competitors (if known)
  • Device bid adjustments reviewed
    Mobile often +20-50% for local/services; Desktop for B2B; Tablet usually -50%
  • Ad schedule set (if applicable)
    Business hours for call-driven; 24/7 for e-commerce; timezone verified

Landing Page & Tracking

  • Landing page loads < 3s mobile
    PageSpeed > 90; LCP < 2.5s; no CLS; optimize images, CSS, JS
  • Message match: Ad → LP congruent
    Same headline, offer, imagery; keyword in H1; clear CTA above fold
  • GA4 events firing on LP
    page_view, scroll, form_start, form_submit, purchase — verify in DebugView
  • UTM parameters on final URLs
    utm_source=google&utm_medium=cpc&utm_campaign={campaignid}&utm_content={adgroupid}&utm_term={keyword}
  • Tracking template set (account level)
    {lpurl}?utm_source=google&utm_medium=cpc&utm_campaign={campaignid}&utm_content={adgroupid}&utm_term={keyword}
  • Mobile experience tested
    Thumb-friendly, no intrusive popups, Apple/Google Pay, click-to-call works

Pre-Launch Verification

  • Policy compliance check
    No prohibited content; landing page compliant; no misleading claims; proper disclosures
  • Budget & bid strategy confirmed
    Daily budget sufficient for learning (50 conv/30d per campaign); bid strategy matches goal
  • Automated rules for safety
    Pause if CPA > 2x target 3 days; Pause if spend > 1.5x daily budget; Email alerts
  • Weekly review calendar blocked
    Monday: Search Terms → Negatives; Breakdowns → Bid Adjustments; Creatives → Pause/Launch
  • Launch in "Observation" mode first
    Audiences on Observation for 1 week → review → switch winners to Targeting

💡 Pro Tip

Launch with audiences on "Observation" only. Let data accumulate for 7 days, then apply bid adjustments to winning segments. Never launch with targeting restrictions you haven't validated.
