No-Code Glossary

Essential terminology for workflow automation, databases, app builders, and AI-powered development

Automation Core Concepts

Workflow
A defined sequence of automated steps connecting triggers to actions across apps. Also called: Zap, Scenario, Flow.
Trigger
Event that starts a workflow: new form submission, webhook received, scheduled time, new database record.
Action
Task performed by workflow: create record, send email, update database, call API, transform data.
Webhook
HTTP callback: app POSTs data to a URL when event occurs. Real-time, no polling. Payload = event data.
Polling
Workflow checks for new data at intervals (e.g., every 5 min). Used when webhooks unavailable.
Data Mapping
Connecting output fields from one step to input fields of next. Transform: format dates, split names, calculate values.
Filter / Condition
Logic to continue only if criteria met: "Only proceed if email contains @company.com" or "Status = Paid".
Router / Branch
Split workflow into multiple paths based on conditions. Each path can have different actions.

Make (Integromat) Specific Terms

Scenario
Make's term for a workflow. Visual flowchart with modules connected by links.
Module
Single step in a scenario: app action, tool (router, iterator, aggregator), or custom function.
Iterator
Loops through array items, running subsequent modules for each item. Essential for batch processing.
Aggregator
Combines multiple bundles into one array or text. Use after Iterator to collect results.
Data Store
Built-in key-value storage within Make. Persist data between scenario runs. 5MB free.
Break / Resume
Error handling: Break stops scenario; Resume continues from error handler module.
Incomplete Executions
Failed runs stored for review. Can be resolved manually and re-run from failure point.

Database & Backend Terms

Base / Workspace
Top-level container (Airtable: Base, Notion: Workspace, Supabase: Project). Contains tables/databases.
Table / Collection
Structured data container with defined fields (columns). Records = rows.
Field / Column / Property
Single data attribute: Text, Number, Date, Select, Multi-select, Attachment, Formula, Relation, Rollup.
Record / Row / Item
Single entry in a table. Unique ID. Contains values for each field.
Relation / Link
Connection between tables. One-to-Many, Many-to-Many. Enables lookups, rollups, joins.
Rollup
Aggregates data from linked records: Count, Sum, Average, Concatenate, Show unique values.
Formula
Computed field: IF, DATEADD, CONCATENATE, REGEX, logical operators. Updates automatically.
View
Saved perspective: Grid, Kanban, Calendar, Gallery, Timeline, Form. Filters, sorts, groups, field visibility.

App Builder Terms

Component
UI building block: Button, Input, Container, List, Chart, Map. Composable, reusable, configurable.
Page / Screen
Route/URL in app. Contains components. Parameters in URL for dynamic pages.
State / Variable
Data that changes: User input, API response, toggle, counter. Local (component) or Global (app-wide).
Action / Workflow (in builder)
Logic triggered by events: On Click, On Load, On Change. Steps: API call, Set State, Navigate, Show Toast.
Auth / Authentication
User management: Sign up, Login, Password reset, Social providers (Google, GitHub), JWT, Sessions, Roles.
Backend / Database Connection
Connect frontend to data: REST API, GraphQL, Supabase, Firebase, Xano, Airtable. CRUD operations.
Responsive Design
Layout adapts: Desktop, Tablet, Mobile. Breakpoints, flex/grid, visibility conditions per device.
Deploy / Publish
Make app live: Custom domain, SSL, CDN, Environment variables, Version history, Rollback.

AI-Powered Development Terms

LLM / Foundation Model
Large Language Model: GPT-4, Claude, Gemini, Llama. Trained on code + text. Powers code generation.
Prompt Engineering
Crafting inputs for optimal AI output: Context, Task, Format, Constraints, Examples (few-shot).
Context Window
Max tokens model can process at once. GPT-4: 128k, Claude: 200k. Affects file size you can feed.
RAG (Retrieval-Augmented Generation)
Fetch relevant docs → inject into prompt → generate answer. Reduces hallucination. Vector DB + Embeddings.
Agent / Autonomous AI
AI that plans, acts, observes, loops: Devin, Cursor Agent, Replit Agent. Multi-step problem solving.
Vibe Coding
Describe what you want in natural language → AI builds it. Iterative refinement via chat.
Code Generation
AI writes: React components, API routes, SQL, tests, docs, configs. Human reviews, integrates, deploys.
Hallucination
AI confidently generates false info: fake APIs, wrong syntax, non-existent libraries. Always verify.
