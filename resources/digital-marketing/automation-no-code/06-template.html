Template 1: Lead Capture → CRM → Email → Slack

Template 2: Appointment Booking → Calendar → Reminders → Prep

Calendly / Cal.com → Google Calendar → Email/SMS → CRM

TRIGGER: Invitee Created (Calendly Webhook) / Booking Confirmed (Cal.com) │ ├─► CREATE: Google Calendar Event (or Outlook) │ Title: "{{Event Type}} — {{Invitee Name}} ({{Company}})" │ Guests: Host + Invitee email │ Location: Video call link (Zoom/Meet) + Physical (if applicable) │ Description: Agenda template + Invitee answers to booking questions │ ├─► UPDATE CRM (HubSpot / Airtable / Pipedrive) │ Log Meeting: Type = "Discovery Call" / "Demo" / "Onboarding" │ Contact: Link to existing or create new │ Deal: Associate if exists │ Activity: Completed = No (will update post-meeting) │ ├─► SEND CONFIRMATION (Email + SMS) │ Email: Calendar invite + "What to prepare" + Reschedule link │ SMS (Twilio): "Confirmed: {{Date}} at {{Time}} for {{Event Type}}. │ Add to calendar: {{Calendar Link}} | Reschedule: {{Link}}" │ ├─► SCHEDULE REMINDERS (Delayed actions) │ 24 hrs before: Email + SMS — "Tomorrow at {{Time}}" │ 1 hr before: SMS only — "Starting in 1 hour: {{Meeting Link}}" │ 5 min before: Push/Slack to host — "Meeting starting: {{Invitee Name}}" │ └─► PRE-MEETING PREP (Trigger: 2 hrs before) Create Notion/Google Doc: "Meeting Notes — {{Invitee Name}}" Template: Agenda, Pain points (from form), Current solutions, Questions Share with host (Slack/Email)

Template 3: Client Onboarding — Payment → Contract → Workspace → Kickoff

Stripe → PandaDoc/DocuSign → Notion/Asana → Slack → Email

TRIGGER: Checkout Session Completed (Stripe Webhook) / Invoice Paid │ ├─► VERIFY: Payment succeeded, amount matches plan, customer email valid │ ├─► GENERATE CONTRACT (PandaDoc / DocuSign / Documint) │ Template: "MSA + SOW — {{Plan Name}}" │ Variables: Client Name, Company, Plan, Price, Start Date, Terms │ Send for signature: Client + Internal signatory │ ├─► ON SIGNATURE COMPLETE (Webhook from DocuSign/PandaDoc) │ │ │ ├─► CREATE CLIENT WORKSPACE │ │ Notion: Duplicate "Client Hub" template → Set permissions │ │ Asana/ClickUp: Create Project from "Client Onboarding" template │ │ Sections: Kickoff, Discovery, Delivery, Reviews, Offboarding │ │ │ ├─► PROVISION ACCESS │ │ Slack: Invite to #client-{{ClientName}} (Shared Channel or Connect) │ │ Google Drive: Create folder → Share with client email │ │ Tools: Figma, Miro, GitHub repo — add as collaborator │ │ │ ├─► WELCOME SEQUENCE │ │ Email 1 (Immediate): "Welcome! Here's your hub + next steps" │ │ Email 2 (+1 day): "Your dedicated team + communication norms" │ │ Email 3 (+3 days): "Kickoff call booked — prep guide attached" │ │ │ └─► SCHEDULE KICKOFF │ Calendly link sent: "Book 60-min Kickoff" │ Auto-create: Asana task "Kickoff Prep" (Due: -1 day) │ ├─► INTERNAL NOTIFICATIONS │ Slack #onboarding: "🎉 New Client: {{Client}} ({{Plan}}) │ PM: {{PM}} | Lead: {{Lead}} | Kickoff: {{Date}} │ 🔗 [Client Hub] [Asana Project] [Contract]" │ Assign: Account Manager, Project Manager, Specialist(s) │ └─► TRACK: Add to "Active Clients" dashboard (Airtable/Notion) Fields: Client, Plan, MRR, Start Date, PM, Health Score, Next Renewal

Template 4: Social Media Posting Pipeline — Content → Approve → Schedule → Analyze

Airtable/Notion → Make → Buffer/Later/Meta → GA4/Sheets

SOURCE: Content Database (Airtable "Content Calendar" / Notion "Content Pipeline") Fields: Title, Copy, Image/Video, Platforms, Status, Scheduled Date, UTM, Approver TRIGGER: Record status = "Ready to Schedule" (Airtable Webhook / Make Scheduler) │ ├─► FOR EACH PLATFORM (Iterator: LinkedIn, Twitter, Instagram, Facebook, Threads) │ │ │ ├─► FORMAT CONTENT │ │ Transform: Copy → Platform-optimized (char limits, hashtags, mentions) │ │ Image: Resize/crop per platform specs (Canva API / Cloudinary) │ │ UTM: Append utm_source={{platform}}&utm_medium=organic&utm_campaign={{campaign}} │ │ │ ├─► SCHEDULE (Buffer / Later / Meta Business Suite API) │ │ Post at: {{Scheduled Date}} + Platform optimal time │ │ Save: Post ID, Scheduled Time, Platform URL │ │ │ └─► UPDATE SOURCE RECORD │ Status: "Scheduled" │ Platform Post IDs: JSON array │ Scheduled Times: Per platform │ ├─► POST-PUBLISH (Webhook from Buffer/Later / Scheduled Check) │ Wait: {{Scheduled Date}} + 24 hrs │ Fetch: Engagement metrics (Likes, Comments, Shares, Clicks, Impressions) │ Update Airtable: Metrics fields populated │ Calculate: Engagement Rate, Click-Through Rate │ ├─► WEEKLY AGGREGATION (Sunday 6pm) │ Rollup: Total posts, Total impressions, Total engagement, Top 3 posts │ Create: "Weekly Social Report" (Google Doc / Notion / Slack) │ Send: To marketing team + leadership │ └─► MONTHLY REVIEW (1st of month) Compare: MoM growth, Best platforms, Content types, ROI (if tracked) Update: Content strategy doc, Platform focus, Budget allocation

Template 5: E-Commerce Order → Invoice → Fulfillment → Review

Shopify/WooCommerce → Documint → Airtable → ShipStation → Judge.me

TRIGGER: Order Created / Paid (Shopify Webhook / WooCommerce Webhook) │ ├─► VALIDATE & ENRICH │ Check: Payment captured, Inventory available, Address valid │ Enrich: Customer tier (VIP/Wholesale), Tags, Marketing consent │ ├─► GENERATE INVOICE (Documint / PDFMonkey / Gotenberg) │ Template: Professional invoice with line items, tax, branding │ Send: Email to customer (Transactional email: SendGrid/Postmark) │ Save: PDF to Google Drive / Airtable Attachment │ ├─► CREATE FULFILLMENT RECORD (Airtable "Orders" table) │ Link: Customer, Line Items, Shipping Method, Warehouse │ Status: "Processing" → "Ready to Pack" → "Shipped" │ Assign: Fulfillment team member │ ├─► INVENTORY SYNC (Bidirectional) │ Airtable Products → Shopify: Decrement stock on order │ Shopify → Airtable: Sync returns, adjustments, incoming PO │ Low Stock Alert: Airtable Automation → Slack #inventory │ ├─► SHIPPING (ShipStation / Shippo / EasyPost) │ Trigger: Airtable Status = "Ready to Ship" │ Rate Shop: Best carrier/service for weight/zone/delivery date │ Create Label: Auto-purchase, print batch, tracking generated │ Update: Shopify (Tracking + Carrier), Airtable (Tracking + Label PDF) │ Email Customer: "Your order shipped! Track: {{Tracking Link}}" │ ├─► DELIVERED WEBHOOK (Carrier / ShipStation) │ Wait: 7 days post-delivery │ Request Review: Judge.me / Yotpo / Loox (Email + SMS) │ NPS Survey: Typeform (1 question: "How likely to recommend?") │ Segment: Promoters → Referral program; Detractors → Support ticket │ └─► REPORTING (Daily 6am) Sync: Orders, Revenue, AOV, Conversion Rate → Google Sheets → Looker Studio Alert: Revenue < 80% 7-day avg → Slack #alerts

Template 6: Support Ticket → Triage → Resolve → Follow-up

Form/Email/Intercom → Linear/Jira → Slack → Customer → Satisfaction

TRIGGER: New Ticket (Typeform / Email Parser / Intercom / Zendesk Webhook) │ ├─► ENRICH & TRIAGE │ Auto-categorize: AI classify (Billing, Technical, Feature, General) │ Priority: SLA rules (VIP = P0, Billing = P1, Feature = P3) │ Assign: Round-robin per category + workload balancing │ Check: Duplicate? (Recent ticket from same customer on same topic) │ ├─► CREATE TRACKING (Linear / Jira / Asana / ClickUp) │ Issue Type: Bug / Task / Question │ Labels: Category, Priority, Customer Tier │ Linked: Customer record (CRM), Related issues │ ├─► NOTIFY & ACKNOWLEDGE │ Slack #support: "🎫 New {{Priority}} Ticket: {{Title}} │ Customer: {{Name}} ({{Tier}}) | Assignee: {{Assignee}} │ SLA: Respond by {{Time}} | Resolve by {{Time}}" │ Auto-reply to Customer: "Received! Ticket #{{ID}}. │ {{Category}} team will respond by {{SLA Time}}." │ ├─► RESOLUTION WORKFLOW │ Assignee works → Updates Linear status: In Progress → In Review → Done │ Internal notes: Private comments in Linear │ Customer updates: Public comments → Email to customer │ Escalation: If SLA breach risk → Auto-escalate to Lead/Manager │ ├─► CLOSE & FOLLOW-UP │ Status = Done → Trigger: "Ticket Resolved" email │ Include: Resolution summary, Link to details, "Reopen if needed" │ Wait 48 hrs → CSAT Survey (1-click: 😊 😐 ☹️ + optional comment) │ CSAT < 3 → Create follow-up task for Manager review │ └─► WEEKLY SUPPORT REPORT Metrics: Volume, First Response Time, Resolution Time, CSAT, Reopen Rate By: Category, Priority, Agent, Customer Tier Trends: Week-over-week, Top issues, Knowledge base gaps
