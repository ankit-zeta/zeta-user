Vector Databases

  • Pinecone
    Fully managed vector database. Serverless, autoscaling, low-latency. Free tier: 100K vectors. Best for production RAG.
    pinecone.io →
    Free TierManagedProduction Ready
  • Weaviate
    Open-source vector search engine. GraphQL API. Built-in vectorization modules. Self-host or cloud.
    weaviate.io →
    Open SourceSelf-HostGraphQL
  • ChromaDB
    Lightweight open-source vector database. Python-first. Great for local development and small projects. pip install chromadb.
    chromadb.com →
    Open SourceLightweightLocal Dev
  • Qdrant
    High-performance vector similarity search. Rust-based. Filtering, payload storage. Self-host or cloud.
    qdrant.tech →
    Open SourceFastRust
  • pgvector (PostgreSQL)
    PostgreSQL extension for vector similarity search. Use your existing Postgres database. No separate infrastructure.
    github.com/pgvector/pgvector →
    Open SourcePostgreSQLSimple
  • Supabase pgvector
    Supabase with built-in pgvector support. Managed PostgreSQL + vector search + auth + storage. One platform for everything.
    supabase.com →
    Free TierManagedAll-in-One

Frameworks & Libraries

  • LangChain
    Python/JS framework for building LLM-powered apps. Chains, agents, RAG pipelines, memory. Large ecosystem.
    langchain.com →
    FrameworkPython/JSRAG
  • Vercel AI SDK
    TypeScript-first AI SDK for Next.js. Streaming, function calling, edge runtime support. Built by Vercel.
    sdk.vercel.ai →
    FrameworkTypeScriptNext.js
  • LlamaIndex
    Data framework for LLM apps. Advanced RAG, document indexing, query engines. Strong for knowledge-heavy apps.
    llamaindex.ai →
    FrameworkRAGData
  • OpenAI Node SDK
    Official OpenAI JavaScript/TypeScript client. TypeScript types, streaming, function calling. Minimal and reliable.
    github.com/openai/openai-node →
    SDKTypeScriptOfficial
  • Streamlit
    Python app framework for ML/data science demos. Turn Python scripts into web apps in minutes. Great for prototyping AI tools.
    streamlit.io →
    FrameworkPythonPrototyping
