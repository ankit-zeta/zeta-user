Client Onboarding Checklist

Discovery call, proposal sent, contract signed, payment received, kickoff meeting, project management setup, communication channels, file sharing

Pre-Sale (Before Proposal)

  • Discovery call completed
    30 min: Problem, goals, budget, timeline, decision-makers, success metrics documented
  • Qualification confirmed
    Budget alignment, authority identified, need validated, timeline realistic (BANT)
  • Proposal customized & sent
    Problem → Solution → Investment → ROI → Next steps. Valid 30 days.
  • Follow-up scheduled
    Calendar invite: "Proposal Review — [Client]" within 3 business days

Contract & Payment

  • Contract reviewed & signed
    Both parties signed (DocuSign/PandaDoc). SOW attached. Terms acknowledged.
  • Deposit invoice sent
    Per payment schedule (typically 30-50%). Due before kickoff.
  • Deposit received & confirmed
    Funds cleared. Receipt sent. Project officially "greenlit."
  • W-9 / Tax forms collected
    If US client paying $600+/yr. Store securely for 1099 filing.
  • Insurance/COI provided (if required)
    Professional liability, General liability. Client added as additional insured if requested.

Kickoff Meeting

  • Kickoff scheduled & confirmed
    60 min. All stakeholders. Calendar invite with agenda sent 48 hrs prior.
  • Agenda distributed
    1. Introductions 2. Project goals & success metrics 3. Timeline & milestones 4. Communication protocol 5. Immediate needs 6. Q&A
  • Single Point of Contact (SPOC) designated
    One client rep for approvals/feedback. Name, email, Slack, phone documented.
  • RACI matrix agreed
    Responsible, Accountable, Consulted, Informed per deliverable. Documented in Notion/Asana.
  • Client dependencies identified
    "We need: Brand assets by [date], Content by [date], API keys by [date], Feedback within 48 hrs."
  • Success metrics defined
    "Launch by [date], Page speed <3s, Conversion rate >3%, Zero critical bugs."

Project Management Setup

  • Project created in PM tool
    Asana/ClickUp/Linear/Notion. Template: "Client Project Standard."
  • Milestones & tasks entered
    From SOW: Phases, deliverables, due dates, assignees, dependencies.
  • Client access granted (view-only)
    Client can see: Milestones, Status, Upcoming. Cannot see: Internal tasks, Time tracking, Costs.
  • Internal team briefed
    Kickoff recording shared. Roles assigned. Questions collected in doc.

Communication Channels

  • Slack Connect / Shared Channel created
    #client-[name] or Slack Connect invite. Primary async communication.
  • Email thread started
    "Project: [Name] — Kickoff" — formal decisions, approvals, invoices.
  • Emergency contact protocol
    "Urgent = Call/Text [PM phone]. Response: 15 min business hours. Non-urgent = Slack/Email (4 hr SLA)."
  • Meeting cadence set
    Bi-weekly sync: [Day] at [Time] [Timezone]. 30 min. Standing invite. Cancel if no agenda.
  • Status report template shared
    Friday 4pm: Wins, Next week, Blockers, Decisions needed. Client gets copy.

File Sharing & Access

  • Shared Drive folder created
    Google Drive / Dropbox / OneDrive. Structure: /Assets, /Deliverables, /Feedback, /Admin.
  • Client assets uploaded
    Brand guidelines, Logos, Fonts, Content, Credentials (in secure note).
  • Design/Dev access provisioned
    Figma (edit), Webflow (designer), GitHub (repo), Staging URL, CMS access.
  • Password manager shared items
    1Password/Bitwarden vault: Client credentials (read-only for team).

First Week Deliverables

  • Kickoff notes distributed
    Decisions, Action items, Owners, Due dates. Sent within 24 hrs.
  • Project brief finalized
    One-pager: Goals, Audience, Key messages, Technical specs, Constraints. Client approves.
  • First milestone work started
    Visible progress within Week 1. Builds confidence.
  • Check-in scheduled (Day 3-5)
    15 min: "How's it going? Any blockers? Adjustments needed?"

💡 Pro Tip

Create an "Onboarding Template" in your PM tool. Duplicate for every client. The first 2 weeks set the tone for the entire engagement. Professional onboarding = fewer scope issues, faster approvals, happier clients.
