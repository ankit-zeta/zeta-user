Development Checklist

Pre-launch, launch, and post-launch checklists for every project

Pre-Development

  • □Define MVP scope: 3-5 core features maximum
  • □Sketch wireframes (Figma, Excalidraw, or paper)
  • □Design database schema and relations
  • □Choose stack: Frontend + Backend + DB + Auth + Hosting
  • □Create GitHub repo with README, .gitignore, LICENSE
  • □Setup local dev: Node.js, package manager, editor, extensions
  • □Configure TypeScript strict mode, ESLint, Prettier
  • □Setup Husky + lint-staged for pre-commit hooks

Development

  • □Setup database: Schema, migrations, seed data
  • □Implement auth: Signup, login, logout, password reset
  • □Build core CRUD for main entity
  • □Add form validation (Zod / react-hook-form)
  • □Implement error handling: Try/catch, error boundaries, toast
  • □Add loading states: Skeletons, spinners, optimistic updates
  • □Responsive design: Mobile-first, test 320px-1440px
  • □Dark mode support (optional but impressive)
  • □Write unit tests for business logic (>80% coverage)
  • □Write integration tests for API routes
  • □Git commits: Conventional commits, meaningful messages

Pre-Deploy

  • □Environment variables: All secrets in .env, not committed
  • □Database connection pooling configured
  • □CORS configured for production domain
  • □Rate limiting on API endpoints
  • □Input sanitization (XSS prevention)
  • □CSRF protection enabled
  • □Security headers (Helmet / next.config.js)
  • □Build succeeds without errors: npm run build
  • □TypeScript passes: npx tsc --noEmit
  • □Lint passes: npm run lint

Launch

  • □Deploy to hosting (Vercel/Railway/Fly.io)
  • □Custom domain + SSL certificate
  • □DNS configured: A/CNAME records
  • □Database migrated on production
  • □Environment variables set in hosting dashboard
  • □Error monitoring (Sentry) initialized
  • □Analytics (PostHog/Plausible) installed
  • □Uptime monitoring (BetterUptime) configured
  • □Test critical flows on production
  • □Share on social: Twitter, LinkedIn, Product Hunt

Post-Launch

  • □Monitor error rates (Sentry dashboard)
  • □Track user analytics (signups, retention, feature usage)
  • □Collect user feedback (Typeform, in-app widget)
  • □Setup CI/CD: Auto-deploy on merge to main
  • □Database backups: Daily automated snapshots
  • □Performance audit: Lighthouse >90, Core Web Vitals
  • □SEO: Meta tags, sitemap, robots.txt, OG images
  • □Documentation: API docs, README, CONTRIBUTING.md
  • □Plan V2 features based on data + feedback

💡 Pro Tip

Use GitHub Projects or Linear to track your checklist. Each item = a card. Move through columns: To Do → In Progress → Done. Visual progress keeps you motivated.
