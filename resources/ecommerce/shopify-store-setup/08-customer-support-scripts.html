Customer Support Scripts

Handle any customer issue with confidence — because support = retention

💬 Common Scenarios

Scenario 1: Order Status Inquiry

"Hi [Name]! Thanks for reaching out. Your order #[Order ID] is currently [status]. Here are the details: 📦 Status: [In Transit/Delivered/Processing] 📅 Expected Delivery: [Date] 🔢 Tracking: [Link] Is there anything else I can help you with?"

Scenario 2: Return Request

"Hi [Name], I'm sorry to hear you'd like to return [Product]. I've initiated the return process. Here's what happens next: 1. You'll receive a return label via email 2. Pack the item securely 3. Drop it off at [Location] 4. Refund will be processed within 5-7 business days Your refund reference: [Reference Number] Any questions? I'm here to help!"

Scenario 3: Damaged Product

"Hi [Name], I'm so sorry about the damaged product! This isn't the experience we want for you. Here's what I'll do: ✅ Immediate replacement shipped (no need to return the damaged one) ✅ 15% discount code for your next order: SORRY15 ✅ Estimated delivery: [Date] You don't need to do anything else. We've got this handled!"

💡 Customer Service Rules

• Respond within 1 hour during business hours
• Always acknowledge the issue first, then solve it
• Offer compensation proactively — don't wait to be asked
• Use the customer's name — it personalizes the experience
• Follow up after resolution — "Is everything working now?"
