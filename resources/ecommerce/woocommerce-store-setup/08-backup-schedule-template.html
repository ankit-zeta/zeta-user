📅 Backup Schedule

Frequency What to Backup Storage Location
Daily Database, uploads, plugins, themes Google Drive / Dropbox
Weekly Full site (files + database) External hard drive / Cloud
Monthly Complete backup with all versions Offsite storage (S3, Backblaze)
Before Updates Full backup before any update Same as daily + local copy

🔧 Backup Setup Steps

UpdraftPlus Configuration

1. Install UpdraftPlus plugin 2. Go to Settings → UpdraftPlus Backups 3. Set backup schedule: - Files: Daily - Database: Daily 4. Choose remote storage (Google Drive recommended) 5. Authenticate with Google account 6. Run first manual backup 7. Verify backup files in Google Drive

💡 Backup Rules

• Follow the 3-2-1 rule: 3 copies, 2 media types, 1 offsite
• Test restore process quarterly — backups are useless if they don't work
• Keep backups for at least 30 days
• Never store backups on the same server
• Document your backup process for your team
