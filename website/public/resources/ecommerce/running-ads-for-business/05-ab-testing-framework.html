A/B Testing Framework

Test everything — because assumptions kill conversions

🔬 What to Test

Element Test Variations Impact
Headlines Benefit vs. Feature, Question vs. Statement High — first thing people see
Images Product vs. Lifestyle, People vs. No People High — visual hook matters
CTA "Buy Now" vs. "Learn More" vs. "Get Started" Medium — drives action
Price Display ₹999 vs. "Just ₹33/day" vs. Crossed-out ₹1499 Medium — perceived value
Social Proof Reviews vs. Numbers vs. Logos Medium — builds trust

📊 Testing Process

4-Step Testing Framework

1. HYPOTHESIZE "I believe [change] will improve [metric] because [reason]" 2. TEST - Run for 7 days minimum - Minimum 100 conversions per variation - Change only ONE variable 3. MEASURE - Statistical significance > 95% - Primary metric: Conversion rate - Secondary: CTR, CPC, ROAS 4. IMPLEMENT - Winner becomes new control - Document learnings - Start next test

💡 Testing Tips

• Test one variable at a time — multiple changes = useless data
• Run tests for full business cycles (7 days minimum)
• Don't stop tests early — even if one "wins"
• Document every test — build a knowledge base
• Test high-impact elements first (headlines, images)
