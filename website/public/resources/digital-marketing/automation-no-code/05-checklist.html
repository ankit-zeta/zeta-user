Automation Setup Checklist

Tool accounts created, integrations connected, workflows tested, error handling added, documentation written, team trained

Account Setup & Access

  • Automation platform accounts created
    Zapier, Make, n8n — team/workspace plan selected based on volume needs
  • App accounts with admin access
    HubSpot, Airtable, Slack, Stripe, Shopify, Calendly, Email platform — admin or integration permissions
  • API keys / tokens generated
    Stored in password manager (1Password, Bitwarden); not in workflow code; rotation schedule set
  • Webhook endpoints configured
    Public URLs with SSL; signature verification enabled; test payloads received
  • Team member access granted
    Role-based: Admin (full), Editor (workflows), Viewer (monitoring); offboarding process documented

Integration Connections

  • Native connections tested
    Each app connected via OAuth/API; test action succeeds (e.g., "Create Contact" in HubSpot)
  • Custom API connections working
    HTTP requests: Auth headers, base URL, rate limit handling, pagination, error codes mapped
  • Data mapping verified
    Source → Destination fields mapped; transforms applied (date format, name split, calculations)
  • Bi-directional sync configured (if needed)
    Airtable ↔ Notion, CRM ↔ Database; conflict resolution rules defined; deduplication keys set
  • Webhook subscriptions active
    Shopify orders, Stripe payments, Calendly bookings, Form submissions — all delivering payloads

Workflow Testing

  • Happy path tested end-to-end
    Real data from trigger → all actions execute → correct result in destination apps
  • Edge cases tested
    Missing fields, duplicate data, API errors, rate limits, empty arrays, null values
  • Error handling verified
    Failed run → Alert sent (Slack/email) → Incomplete execution stored → Manual retry works
  • Idempotency confirmed
    Re-running same trigger payload = no duplicate records (unique keys: email, transaction_id)
  • Performance benchmarks met
    Execution time < 30s (simple), < 5 min (complex); ops/tasks within plan limits
  • Load test (if high volume)
    Simulate 10x expected volume; check queue depth, memory, timeout settings

Monitoring & Alerting

  • Failure alerts configured
    Slack channel #automation-alerts; Email to owner; PagerDuty for critical workflows
  • Success metrics tracked
    Runs/day, Success rate, Avg duration, Queue depth — dashboard in Make/Zapier or custom
  • Usage alerts set
    Tasks/operations > 80% of plan limit → notification; auto-upgrade or optimization triggered
  • SLA defined
    Critical workflows: 99.9% uptime, < 5 min recovery; Standard: 99% uptime, < 1 hr recovery

Documentation & Knowledge Transfer

  • Workflow documentation complete
    Name, Purpose, Trigger, Apps, Data Flow, Owner, Last Updated, Run History Link, Troubleshooting
  • Architecture diagram created
    Visual: Apps → Connections → Data Flow → Error Paths (Miro, FigJam, Draw.io)
  • Runbook for common issues
    "If HubSpot create fails → check API limit → wait 5 min → retry"; "If webhook not firing → check endpoint SSL"
  • Credentials documented (securely)
    Which vault, which item names, rotation schedule, emergency access process
  • Team training completed
    Demo: How to view runs, how to replay, how to pause, how to escalate; recording saved

Maintenance & Optimization

  • Weekly review scheduled
    Monday: Check failed runs, review metrics, optimize slow workflows, clean incomplete executions
  • Monthly audit scheduled
    Usage vs plan, unused workflows, deprecated API versions, new app features to adopt
  • Quarterly architecture review
    Consolidate duplicate workflows, migrate to newer tools, evaluate ROI, plan next automations
  • Backup / export strategy
    Workflow definitions exported (JSON); credentials backed up; disaster recovery tested

💡 Pro Tip

Create a "Automation Registry" in Notion/Airtable: one row per workflow with columns for all checklist items. Filter by status, owner, last reviewed. Single source of truth for your automation estate.
