A/B Testing Framework

What to Test (Priority Order)

1. Value proposition / headline
2. CTA (text, color, placement)
3. Social proof (testimonials, logos, numbers)
4. Page layout / form length
5. Pricing display / tiers
6. Images / videos
7. Urgency elements (countdown, scarcity)

A/B Test Requirements

Sample size: 1,000+ visitors per variation
Duration: Minimum 2 weeks (full business cycle)
Statistical significance: 95%+ confidence
One variable: Test only ONE thing at a time
Document: Record hypothesis, results, learnings

Test Documentation Template

Hypothesis: "If we [change], then [metric] will [improve] because [reason]"
Metric: Primary (CVR) + Secondary (AOV, Bounce)
Duration: [Start] to [End]
Result: [Win/Lose/Inconclusive]
Lift: [% change in metric]
Confidence: [% statistical significance]

Common A/B Test Mistakes

❌ Stopping too early (need 2+ weeks)
❌ Testing too many things at once
❌ Ignoring statistical significance
❌ Testing trivial changes (button radius)
❌ Not having a clear hypothesis
✅ Test high-impact changes first

Cohort Analysis

What is Cohort Analysis?

Groups users by shared characteristic (signup date, first purchase, acquisition channel) and tracks their behavior over time. Reveals trends hidden in aggregate data.

Key Cohort Metrics

Retention curve: % returning over time
Revenue per cohort: Which cohorts spend most
LTV by cohort: Long-term value comparison
Churn curve: When users drop off
Activation rate: % completing key action

Cohort Analysis Use Cases

Compare: Pre/post product change impact
Channel: Which acquisition source has best LTV
Seasonality: Q1 vs Q4 customer behavior
Pricing: Impact of price change on retention
Onboarding: Before/after onboarding redesign

Cohort Retention Benchmarks

SaaS Day 1: 40-60% return
SaaS Day 7: 20-30% return
SaaS Day 30: 10-20% return
E-commerce 30-day: 15-25% repeat
E-commerce 90-day: 25-40% repeat

Pro Tip

Growth analytics is about finding the biggest bottleneck and fixing it. Don't track 50 metrics — pick 3-5 that directly impact revenue. CAC, LTV, and conversion rate at each funnel stage tell you exactly where to focus.
