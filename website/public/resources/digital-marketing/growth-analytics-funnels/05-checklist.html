Growth Analytics Checklist

Analytics setup, funnel analysis, cohort tracking, A/B testing, and optimization checklists

Setup: Tracking & Dashboards

  • GA4 installed and configured
    gtag.js on all pages, enhanced measurement enabled, conversion events created, filters applied.
  • Key events defined and firing
    page_view, scroll, form_start, form_submit, purchase, sign_up — verify in DebugView.
  • Product analytics tool configured
    Mixpanel, Amplitude, or PostHog. User properties set. Events mapped to funnel stages.
  • Session recording tool installed
    Hotjar or Microsoft Clarity (free). Heatmaps on key pages. Recordings filtered to conversion pages.
  • UTM parameters standardized
    utm_source, utm_medium, utm_campaign naming convention documented. Team trained on usage.
  • Dashboard created
    Looker Studio or spreadsheet. Shows: traffic, conversion rate, CAC, LTV, revenue. Updated weekly.

Analyze: Funnels & Cohorts

  • Complete funnel mapped
    All stages from awareness to retention. Conversion rates at each stage. Biggest drop-off identified.
  • Top 3 funnel leaks identified
    Ranked by impact (revenue lost). Root cause hypothesis for each. Prioritized by effort vs impact.
  • Cohort analysis set up
    At least 2 cohort types: acquisition date + acquisition channel. Tracking retention curves.
  • Activation event defined
    The one action that predicts retention. Tracked and measured. Baseline documented.
  • CAC and LTV calculated
    By channel, by cohort. LTV:CAC ratio calculated. Benchmarked against industry standards.
  • Weekly analytics review scheduled
    30 min every Monday. Review funnel, check anomalies, plan tests. Calendar invite sent.

Optimize: Tests & Iterations

  • A/B test backlog created
    10+ test ideas ranked by impact. Each has hypothesis, metric, sample size, duration.
  • First A/B test launched
    Highest-impact test running. Statistical significance calculator ready. 2-week minimum duration.
  • Test results documented
    Hypothesis, result, lift, confidence, learning. Winner implemented or next test started.
  • Guardrail metrics monitored
    During tests, watching for unintended consequences. NPS, churn, support tickets tracked.
  • Top 3 leaks addressed
    Fixes shipped for biggest funnel problems. Impact measured post-fix. Revenue impact documented.
  • Next month test plan ready
    Minimum 2 tests planned. Resources allocated. Dependencies identified. Start dates set.

Pro Tip

Don't try to do everything at once. Complete the Setup section first (Week 1), then Analyze (Week 2), then Optimize (Week 3+). Most businesses skip setup and jump to testing — they end up making decisions on bad data.
