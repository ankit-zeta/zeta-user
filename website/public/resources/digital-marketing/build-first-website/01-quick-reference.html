CSS Box Model

CSS
.box { width: 300px; padding: 20px; border: 2px solid #176B4D; margin: 10px; box-sizing: border-box; /* includes padding & border in width */ }

Flexbox Quick Reference

CSS
.container { display: flex; justify-content: center; /* horizontal alignment */ align-items: center; /* vertical alignment */ gap: 20px; flex-wrap: wrap; } .item { flex: 1; /* grow shrink basis */ }

CSS Grid Quick Reference

CSS
.grid { display: grid; grid-template-columns: repeat(3, 1fr); grid-template-rows: auto 1fr auto; gap: 20px; } .header { grid-column: 1 / -1; }
