Exercise 7: CSS Custom Properties (Variables)

Refactor colors and spacing to CSS variables

Define a design system using CSS custom properties for consistent theming.

CSS
:root { --color-primary: #176B4D; --color-secondary: #0f4d36; --color-text: #1a1a1a; --color-text-light: #666; --spacing-xs: 8px; --spacing-sm: 16px; --spacing-md: 24px; --spacing-lg: 48px; --radius-sm: 4px; --radius-md: 8px; } .btn { background: var(--color-primary); padding: var(--spacing-sm) var(--spacing-md); }

Exercise 8: Deploy to Netlify/Vercel

Deploy your static site for free

Push to GitHub and connect to Netlify or Vercel for automatic deployments.

  • Initialize git: git init && git add . && git commit -m "Initial commit"
  • Create GitHub repo and push: git push -u origin main
  • Import project in Netlify/Vercel — auto-detects static site
  • Custom domain: add in dashboard DNS settings

💡 Pro Tip

Build incrementally — commit after each exercise. If something breaks, you can always revert to a working version.
