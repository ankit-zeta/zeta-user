Optimization Cheat Sheet

Quality Score improvement, ad copy testing, keyword match type adjustments, bid modifiers, ad scheduling, geo targeting

Quality Score Improvement

Expected CTR (Biggest Lever)

• Tighten ad groups (15-20 keywords max)
• Write specific ads per ad group theme
• Use all ad extensions (sitelinks, callouts, snippets)
• Test RSA vs RSA (not vs old ETA)
• Add negative keywords weekly

Ad Relevance

• Include keyword in Headline 1
• Match ad copy to search intent (buy/learn/compare)
• Use DKI (Keyword Insertion) in H1
• Separate brand vs non-brand campaigns
• Single-theme ad groups (STAGs)

Landing Page Experience

• Keyword in H1 & first paragraph
• Page load < 3s mobile (PageSpeed > 90)
• Clear CTA above fold, no popups
• Mobile-first design, thumb-friendly
• Trust signals: reviews, badges, guarantee

Quick Wins

• Pause QS 1-3 keywords (or move to own AG)
• Add sitelinks to all campaigns
• Enable Dynamic Search Ads for coverage
• Check: Keywords → Columns → Quality Score sections

Ad Copy Testing Framework

Test ONE Variable at a Time

• Headline 1 (pin vs unpin)
• Description 1 (benefit vs feature)
• CTA text (Shop Now vs Get Quote)
• Offer (% off vs $ off vs free shipping)
• Pinning strategy (pin H1 vs pin none)

RSA Testing Best Practices

• 2-3 RSAs per ad group max
• Each RSA = distinct angle (not minor tweaks)
• Run 2-4 weeks or 1000+ impressions
• Winner = lowest CPA / highest ROAS
• Pause losers, iterate winners

Ad Copy Formulas to Test

• PAS (Problem-Agitate-Solution)
• AIDA (Attention-Interest-Desire-Action)
• Before-After-Bridge
• Feature-Advantage-Benefit (FAB)
• Question-Answer-Proof

Seasonal/Promo Testing

• Holiday-specific creative (Q4, Back-to-School)
• Countdown timers in descriptions
• Limited inventory language
• Free gift vs discount A/B test
• Urgency vs value proposition

Keyword & Match Type Optimization

Search Terms Report (Weekly)

• Add converting queries as exact/phrase keywords
• Add irrelevant queries as negatives (exact match)
• Identify new ad group themes
• Spot match type expansion issues

Match Type Strategy

• Phrase = default (balance)
• Exact = high-value, high-volume terms
• Broad = Smart Bidding only (Target CPA/ROAS)
• Negative = aggressive, campaign + ad group level

Keyword Lifecycle

• New → Test in broad/phrase (Smart Bidding)
• Performing → Move to exact, own ad group
• Declining → Pause, add negatives, refresh creative
• Dead → Remove after 90 days no conversions

Keyword Expansion

• Keyword Planner: new seed terms monthly
• Competitor gaps: Semrush/Ahrefs quarterly
• Search Terms: weekly mining
• DSA (Dynamic Search Ads): gap filling

Bid Modifier Strategy

Device Modifiers

• Mobile: +20-50% (local, services, calls)
• Desktop: +20-50% (B2B, complex purchases)
• Tablet: -50% to -100% (usually poor ROI)
• Set at campaign level, review monthly

Location Modifiers

• +Bid: High-converting cities/regions
• -Bid: Low-converting, high-CPA areas
• Exclude: Non-serviceable locations
• Radius: +Bid near physical locations

Ad Schedule Modifiers

• +Bid: Business hours (call-driven)
• +Bid: Peak conversion hours (check by hour report)
• -Bid: Low-activity hours (2am-5am)
• Use: Lifetime budget campaigns only

Audience Bid Modifiers

• Remarketing (cart abandoners): +50-100%
• Remarketing (visitors): +20-30%
• In-Market (high intent): +15-25%
• Customer Match (lookalike): +10-20%
• Demographics (converting age/gender): +10-20%

Monday (30 min)

• Search Terms Report → Add negatives

• Check Quality Score changes
• Review budget pacing

Wednesday (20 min)

• Ad performance → Pause losers
• Extension performance → Optimize
• Device/Location/Audience breakdowns → Bid mods
• Ad schedule → Adjust bid modifiers

Friday (15 min)

• Budget pacing for week
• Competitor check (Auction Insights)
• Plan next week's tests
• Update negative keyword master list

Monthly (60 min)

• Full account audit
• Landing page audit (new vs returning)
• Attribution model review
• Bid strategy evaluation (Manual → Smart?)

Troubleshooting Common Issues

High CPC / Low Impression Share

• Improve Quality Score (see above)
• Add more relevant keywords
• Increase budget (if profitable)
• Expand to phrase/broad (Smart Bidding)
• Check: Lost IS (Rank) vs Lost IS (Budget)

High CPA / Low ROAS

• Pause high-CPA keywords/ads
• Add negatives from Search Terms
• Improve landing page CVR
• Switch to Target CPA/ROAS (if 30+ conv)
• Check: Mobile vs Desktop performance

Low Click Volume

• Expand keyword list (broad match + Smart Bidding)
• Increase bids (if Manual CPC)
• Add more ad groups / campaigns
• Check: Ad Strength, ad disapprovals
• Try Performance Max for reach

Conversion Tracking Issues

• Verify Tag Assistant / GTM Preview
• Check Enhanced Conversions status
• Verify GA4 events in DebugView
• Test offline import (GCLID format)
• Check: Consent Mode (EU/UK)
