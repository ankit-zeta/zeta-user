Key Metrics Definitions

Users

Unique individuals (Active Users in GA4). 28-day active window by default.

Sessions

Periods of engagement. 30-min inactivity timeout. New session = new source/medium or midnight.

Engaged Sessions

Sessions >10s OR 1+ conversion OR 2+ pageviews. Better quality indicator than bounce rate.

Engagement Rate

Engaged Sessions ÷ Sessions. Replaces Bounce Rate. Target > 50% (varies by industry).

Average Engagement Time

Total engagement time ÷ Active Users. Time user actively interacts (tab visible).

Events

User interactions: page_view, scroll, click, video_play, form_submit, purchase, etc.

Conversions

Events marked as conversions. Count: Once per session (default) or Once per event.

Event Parameters

Additional context: page_location, item_id, value, currency, method, form_id, etc.

Consistency Rules

• Always lowercase
• Underscores not spaces
• No special characters
• Document in shared sheet
• Use builder tool (GA URL Builder)

Auto-Tagging (Google Ads)

Enable: Settings → Account Settings → Auto-tagging: ON
Adds gclid parameter automatically
Required for GA4 + Ads integration

Cross-Domain Tracking

Admin → Data Streams → Configure Tag Settings → Domains
Add all domains user traverses
Ensures session continuity

Segments & Audiences

Segment (Analysis)

Subset of data for Explore reports. Session/User/Event scope. Ad-hoc, not reusable across reports.

Audience (Reusable)

Defined in Admin → Audiences. Used in: Reporting comparisons, Google Ads targeting, Export to BigQuery. Max 100 audiences.

Suggested Audiences

• 7-day active users
• Purchasers (lifetime)
• High-value purchasers (top 10%)
• Cart abandoners
• Form abandoners
• Blog readers (3+ articles)
• Video completers

Predictive Audiences (GA4)

• Likely 7-day purchasers
• Likely 7-day churners
• Predicted 28-day revenue top 10%
Requires: 1000+ purchasers/1000+ churners in 28 days

Debugging & Validation

DebugView (GA4)

Admin → DebugView. Real-time event stream for your device. Enable: GTM Preview, GA Debugger extension, or debug_mode parameter.

GA Debugger Extension

Chrome extension. Logs all GA4 hits to console. Shows parameters, warnings, errors. Essential for implementation QA.

GTM Preview Mode

GTM → Preview. Test tag firing, variable values, data layer. Shareable preview link for team.

Realtime Report

Reports → Realtime. Verify events firing live. Check: Active users, Events (last 30 min), Conversions.

💡 Pro Tip

Create a "Measurement Plan" doc before implementing: Business Objectives → KPIs → Events → Parameters → Audiences → Reports. Share with dev team. Prevents "track everything" chaos.
