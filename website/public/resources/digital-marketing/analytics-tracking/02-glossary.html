Analytics Glossary

Essential terminology for GA4, event tracking, attribution, and data analysis

Core Concepts

Session
Period of user engagement. Starts with first event, ends after 30 min inactivity or midnight. New campaign source = new session.
User
Unique individual (identified by User ID or Device ID). Active User = engaged session in last 28 days.
Event
Any user interaction: page_view, click, scroll, purchase. Foundation of GA4 data model. Name + Parameters.
Parameter
Additional context for events. page_location, item_id, value, currency, engagement_time_msec. Max 25 params/event.
Conversion
Event marked as valuable. Count: Once per session (default) or Once per event. Mark in Admin → Events.
Engagement Rate
Engaged Sessions ÷ Sessions. Engaged = >10s OR 1+ conversion OR 2+ pageviews. Replaces Bounce Rate.
Attribution Model
Rules assigning conversion credit: Data-Driven (ML), Last Click, First Click, Linear, Time Decay, Position-Based.
Dimension
Attribute of data: source, medium, campaign, device, country, page_title, event_name. What you analyze BY.

GA4-Specific Terms

Data Stream
Data source: Web, iOS App, Android App. Each has Measurement ID (G-XXXXXXXX). Enhanced Measurement auto-events.
Measurement ID
G-XXXXXXXX format. Replaces UA-XXXXXX-X. One per data stream. Used in gtag/GTM config.
Enhanced Measurement
Auto-collects: scroll, video_play, file_download, form_start, form_submit, search, click (outbound). Toggle per stream.
Data-Driven Attribution
ML model assigning credit based on actual paths. Default in GA4. Requires 300 conversions/30d + 3k visits.
Explore
Custom analysis workspace. Techniques: Free Form, Funnel, Path, Segment Overlap, Cohort, User Lifetime.
BigQuery Export
Raw event-level export to BigQuery. Daily or streaming. Enables SQL analysis, ML, custom dashboards. Free tier: 10GB/mo.
Consent Mode v2
Adjusts tag behavior based on user consent (ad_storage, analytics_storage). Required for EEA/UK traffic.
User ID
Your CRM ID for cross-device tracking. Set via gtag('set', 'user_id', 'ID'). Enables User Explorer, cross-device reports.

E-Commerce & Monetization Terms

Ecommerce Events
Standard events: view_item, add_to_cart, remove_from_cart, begin_checkout, add_payment_info, purchase, refund.
Items Array
Array of item objects in ecommerce events: item_id, item_name, price, quantity, item_brand, item_category, item_variant.
Transaction ID
Unique order identifier (string). Required for purchase/refund. Prevents duplicate counting.
Currency
ISO 4217 code (USD, EUR, GBP). Required for monetary events. GA4 converts to property currency.
Value
Monetary value (number). For purchase: total revenue. For lead: estimated value. Required for ROAS/ROI.
Item Scoped Dimensions
Dimensions tied to items: item_name, item_brand, item_category, item_variant. Used in Ecommerce reports.
Promotion Events
view_promotion, select_promotion. Track internal promo impressions/clicks. promotion_id, promotion_name, creative_name, creative_slot.

Attribution & Marketing Terms

UTM Parameters
Campaign tracking tags: utm_source, utm_medium, utm_campaign, utm_content, utm_term. Append to URLs.
gclid / wbraid / gbraid
Google Click ID (auto-tagging). wbraid/gbraid for iOS 14+. Enables Ads ↔ GA4 conversion linking.
Channel Grouping
Rule-based grouping of source/medium: Organic Search, Paid Search, Organic Social, Paid Social, Email, Referral, Direct.
Default Channel Group
GA4's built-in channel grouping. Customizable in Admin → Data Settings → Channel Groups.
Assisted Conversion
Channel contributed to conversion path but wasn't final touch. View in Advertising → Conversion Paths.
Conversion Path
Sequence of channel touchpoints leading to conversion. Length, time lag, channel sequence.
Lookback Window
Time before conversion to consider touchpoints. Default 30 days (configurable 1-90 days).
Cross-Network
Channel for Performance Max / Smart Shopping where Google doesn't disclose specific network.

Technical & Implementation Terms

gtag.js
Google's unified tag library. gtag('config', 'G-XXXXXXXX'); gtag('event', 'name', {params});
Data Layer
JavaScript array (window.dataLayer) holding structured data. GTM reads from it. Single source of truth.
Google Tag Manager (GTM)
Tag management system. Container tag on site. Triggers fire tags based on data layer/events. Version control.
Container
GTM workspace holding tags, triggers, variables. Published versions. Environments: Live, Preview, Custom.
Trigger
Condition that fires a tag: Page View, Click, Form Submit, Custom Event, Timer, Scroll Depth, YouTube Video.
Variable
Dynamic value used in tags/triggers: Built-in (Page URL, Click Text), Data Layer, Custom JS, Constant, Lookup Table.
Server-Side GTM
GTM running on your server (Cloud Run, App Engine). Better privacy, ad blocker resistance, data enrichment. Advanced.
Enhanced Conversions
Hashes PII (email, phone, name, address) sent with conversions. Improves matching accuracy. Required for Ads.
