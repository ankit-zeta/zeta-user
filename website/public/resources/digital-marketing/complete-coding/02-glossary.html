Full-Stack Glossary

Essential terminology for React, Node.js, databases, APIs, deployment, and modern development workflows

Frontend & React

Component
Reusable UI building block. Function or class returning JSX. Props in, UI out. Composable, testable.
Props
Read-only inputs passed to components. Like function arguments. Type with TypeScript interfaces.
State
Component-local mutable data. Triggers re-render on change. useState, useReducer, useContext.
Hook
Function to use React features in function components. useState, useEffect, useContext, useMemo, useCallback, custom hooks.
Virtual DOM
Lightweight JS representation of real DOM. React diffs changes, batches updates for performance.
JSX
JavaScript XML. Syntax extension: write HTML in JS. Transpiles to React.createElement(). Type-safe with TS.
SSR / SSG / ISR
Server-Side Rendering, Static Site Generation, Incremental Static Regeneration. Next.js rendering strategies.
Hydration
Process of attaching event listeners to server-rendered HTML. Makes static HTML interactive.

Backend & Node.js

Middleware
Function with access to req, res, next. Runs between request and response. Auth, logging, validation, error handling.
Controller
Handles HTTP request: parses input, calls service, formats response. Thin layer, delegates to services.
Service Layer
Business logic: data transformation, external API calls, transactions. Reusable, testable, framework-agnostic.
ORM (Prisma/Drizzle)
Object-Relational Mapping. Type-safe DB access. Schema definition, migrations, queries, relations. No raw SQL needed.
Migration
Version-controlled schema changes. Up/Down functions. Run in CI/CD. Prisma: prisma migrate dev/deploy.
Connection Pool
Reusable DB connections. Avoids handshake overhead. PgBouncer for Postgres. Size based on CPU cores.
N+1 Problem
Fetching parent then N children in separate queries. Fix: JOIN, include(), DataLoader, batch loading.

Database & API

ACID
Atomicity, Consistency, Isolation, Durability. Transaction guarantees. Postgres: full ACID.
Index
Data structure for fast lookups. B-tree (default), Hash, GIN, GiST. Trade-off: write speed vs read speed.
Foreign Key
Column referencing another table's PK. Enforces referential integrity. ON DELETE CASCADE/SET NULL.
REST
Representational State Transfer. Resource-based URLs, HTTP verbs, stateless, cacheable, uniform interface.
GraphQL
Query language: client requests exact data. Single endpoint. Schema-first. Resolvers. N+1 risk (DataLoader).
tRPC
End-to-end typesafe APIs. No schema/codegen. Inference from backend to frontend. Great for TypeScript monorepos.
Webhook
HTTP callback for real-time events. Stripe, GitHub, Clerk. Verify signatures. Idempotency keys.

Auth & Security

JWT (JSON Web Token)
Stateless auth: Header.Payload.Signature. Access (short) + Refresh (long) tokens. Store in HttpOnly cookie.
bcrypt / Argon2
Password hashing. Slow, memory-hard. Cost factor 12+. Never use MD5/SHA. Verify: compare(hash, plain).
OAuth 2.0 / OIDC
Authorization framework. Google, GitHub, Microsoft providers. Scopes, PKCE, State parameter, Token exchange.
MFA / 2FA
Multi-Factor Auth. TOTP (Authenticator apps), SMS (less secure), WebAuthn (passkeys). Required for admin.
CSRF / XSS
Cross-Site Request Forgery (same-site cookies, CSRF tokens). Cross-Site Scripting (sanitize, CSP, HttpOnly).
Rate Limiting
Prevent abuse: Fixed window, Sliding window, Token bucket. Per IP, user, API key. Return 429 + Retry-After.
CORS
Cross-Origin Resource Sharing. Browser security. Allow origin, methods, headers, credentials. Preflight OPTIONS.
Helmet / CSP
Security headers: X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Content-Security-Policy.

DevOps & Deployment

CI/CD
Continuous Integration / Deployment. Automate: Lint → Test → Build → Deploy. GitHub Actions, GitLab CI, CircleCI.
Docker
Containerization. Image = layered filesystem. Container = running instance. Dockerfile, compose, multi-stage.
Kubernetes (K8s)
Container orchestration. Pods, Services, Deployments, Ingress, ConfigMaps, Secrets. Overkill for small apps.
Edge Computing
Run code near users: Cloudflare Workers, Vercel Edge, Deno Deploy. Low latency, limited runtime.
Observability
Logs, Metrics, Traces. Structured JSON logs. OpenTelemetry. Datadog, Grafana, Sentry, Axiom.
Blue/Green / Canary
Deployment strategies. Blue/Green: instant switch. Canary: gradual rollout. Feature flags for safety.
Infrastructure as Code
Terraform, Pulumi, AWS CDK. Version-controlled infra. Plan → Apply. State management critical.
Secret Management
Never commit secrets. 1Password, Vault, AWS Secrets Manager, Doppler, .env.local (local only). Rotate regularly.
