DevOps & Deployment

Git Workflow

main branch, feature branches, PR reviews, conventional commits, rebasing, tags, releases, GitHub Actions

Containerization

Dockerfile, docker-compose, multi-stage builds, .dockerignore, security scanning, distroless images

CI/CD

GitHub Actions: Lint → Typecheck → Test → Build → Deploy. Environments: Preview, Staging, Production

Hosting Platforms

Vercel (Next.js), Netlify, Railway, Render, Fly.io, AWS, GCP, Cloudflare Pages. Edge functions, ISR, Analytics

Testing Strategy

Unit Tests

Vitest/Jest: Pure functions, hooks, utils. Fast, isolated. Target: >80% coverage on business logic

Integration Tests

API routes, DB operations, Auth flows. Testcontainers for DB. Supertest for Express/Next.js

E2E Tests

Playwright/Cypress: Critical user flows (signup, checkout, dashboard). Run in CI on preview deploys

Static Analysis

ESLint, Prettier, TypeScript, SonarQube, Husky pre-commit, lint-staged

💡 Pro Tip

Build in public: Deploy every week. Ship a "walking skeleton" (auth + deploy + DB) in week 1. Add features vertically (full stack per feature), not horizontally (all frontend, then all backend).
