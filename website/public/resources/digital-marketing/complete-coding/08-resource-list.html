Coding Resources

Best free and paid resources to learn full-stack development from zero to advanced

Structured Courses (Beginner)

  • The Odin Project
    Free, open-source full curriculum. HTML/CSS → JavaScript → React/Ruby on Rails. Project-based. Community Discord. Best free option.
    theodinproject.com →
    FreeFull CurriculumProjects
  • freeCodeCamp
    Free, certification-based. Responsive, JS, Frontend, Backend, Data. 3000+ hours. Responsive design, algorithms, APIs. Great for beginners.
    freecodecamp.org →
    FreeCertificationsBeginner
  • Full Stack Open (Helsinki)
    University-level. React, Node, MongoDB, Testing, CI/CD, GraphQL, TypeScript. Free. Excellent exercises and grading system.
    fullstackopen.com →
    FreeUniversityModern Stack
  • CS50 Web (Harvard)
    Harvard's CS50 for web. Python, Django, SQL, JavaScript, React. Free. Problem sets + final project. Academic rigor.
    cs50.harvard.edu/web →
    FreeHarvardPython/Django
  • 100 Days of Code (Angela Yu)
    Udemy: Python, web, APIs, databases. One project per day. Beginner-friendly. ~$15 on sale. Best structured daily habit.
    udemy.com →
    PaidDailyPython

Intermediate / Advanced

  • JavaScript.info
    Complete JS reference + tutorial. Modern ES6+, Promises, async, modules. Interactive exercises. Free. Best JS reference.
    javascript.info →
    FreeReferenceES6+
  • Total TypeScript (Matt Pocock)
    Advanced TypeScript: Generics, Utility types, Type narrowing, Zod integration. ~$200. Best for going beyond basics.
    totaltypescript.com →
    PaidAdvancedTypeScript
  • Egghead.io
    Video tutorials: React, Next.js, Node, GraphQL. Industry experts. Short, focused courses. Free + paid. $25/mo unlimited.
    egghead.io →
    VideosExpertShort
  • Frontend Masters
    Premium video courses. React, Node, System Design, Performance. Industry experts. $39/mo. Worth it for serious learners.
    frontendmasters.com →
    PremiumVideoExpert
  • Boot.dev
    Backend-focused: Python, Go, SQL, APIs. Gamified: XP, levels, quests. Free tier. $29/mo. Great for backend specifically.
    boot.dev →
    BackendGamifiedPython/Go

Practice & Challenges

  • LeetCode
    Algorithm challenges. Interview prep. 2000+ problems. Free. Discuss solutions. Premium: $35/mo. Essential for big tech interviews.
    leetcode.com →
    AlgorithmsInterviewsFree Tier
  • Exercism
    Practice tracks: 50+ languages. Mentoring available. Free. Strong fundamentals. Not interview prep — pure skill building.
    exercism.org →
    Free50+ LanguagesMentoring
  • Codewars
    Kata challenges. Rank from 8kyu to 1kyu. Competitive. Free. Good for daily practice habit. Many languages.
    codewars.com →
    FreeGamifiedDaily
  • Frontend Mentor
    Real-world HTML/CSS/JS projects. Professional designs. Free. Beginner to advanced. Build portfolio while learning.
    frontendmentor.io →
    FreeReal ProjectsPortfolio

Documentation & References

  • MDN Web Docs
    Mozilla's web reference. HTML, CSS, JS, HTTP, Web APIs. Official, comprehensive. Free. The Bible of web development.
    developer.mozilla.org →
    FreeOfficialReference
  • Next.js Docs
    Official. App Router, API routes, SSR, ISR, middleware, deployment. Excellent examples. Free. Read before using Next.js.
    nextjs.org/docs →
    FreeOfficialNext.js
  • Prisma Docs
    ORM documentation. Schema, queries, migrations, deployment, performance. Great examples. Free. Best ORM docs.
    prisma.io/docs →
    FreeORMDatabase
  • TypeScript Handbook
    Official TS guide. Types, interfaces, generics, utility types, configuration. Interactive examples. Free. Essential.
    typescriptlang.org →
    FreeOfficialTypeScript

💡 Pro Tip

Don't tutorial-hop. Pick ONE structured course (The Odin Project or Full Stack Open). Complete it. Then use docs + challenges to fill gaps. Build 3 portfolio projects. Apply for jobs.
