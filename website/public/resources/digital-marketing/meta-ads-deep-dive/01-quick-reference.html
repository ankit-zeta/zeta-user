Audience Types

Core Audiences

Demographics: Age, gender, location, language
Interests: Hobbies, pages liked, activities
Behaviors: Purchase intent, device usage, travel
Connections: Page followers, app users, event responders

Custom Audiences

Website visitors (Pixel)
Customer list (email/phone upload)
App activity (SDK)
Engagement (video, lead form, IG/FB page, events)
Offline activity (store visits, CRM)

Lookalike Audiences

1% = Most similar (smallest, highest quality)
2-3% = Balanced reach/quality
5-10% = Broad reach, lower similarity
Source: Custom Audience (min 100 people)
Create multiple for testing

Advantage+ Audiences

Meta's AI-powered targeting
Inputs: Age, gender, location (constraints)
Signals: Pixel data, engagement, conversion history
Best for: Conversion campaigns with sufficient data
Test against manual targeting

Budget Types

Daily Budget

Average spend per day
Meta may spend up to 2x daily (averages over week)
Good for: Ongoing campaigns, testing
Min: $1/day (impressions), $5/day (clicks/conversions)

Lifetime Budget

Total spend over campaign dates
Evenly paced or accelerated
Good for: Fixed-duration promotions, events
Schedule: Set start/end dates

Campaign Budget Optimization (CBO)

Budget at campaign level
Meta distributes to best ad sets
Default for new campaigns
Less manual control, better automation

Ad Set Budget (ABO)

Budget at ad set level
Manual control per audience
Good for: Testing, specific allocations
Disable CBO to use

Campaign Structure Best Practices

Naming Convention

Campaign: [Objective]_[Geo]_[Product]_[Date]
Ad Set: [Audience]_[Placement]_[CreativeTheme]
Ad: [Format]_[Hook]_[Variation]
Example: CONV_US_Shoes_Jan24 / LAL_1%_Feed_Video / VID_Hook1_V1

Testing Structure

1 Campaign → 3-5 Ad Sets (audiences)
Each Ad Set → 3-5 Ads (creatives)
Test ONE variable at a time
Statistical significance: 50+ conversions per variant

Funnel Structure

TOF: Awareness/Traffic → Broad/Interest
MOF: Engagement/Video Views → Retargeting
BOF: Conversions/Sales → Custom/Lookalike
Separate campaigns per funnel stage

Creative Testing

Dynamic Creative: Auto-combine assets
Creative Testing: Controlled A/B test
Iterate: Hook → Body → CTA → Visual
Refresh every 2-4 weeks

💡 Pro Tip

Start with Sales/Conversions objective + Advantage+ Audience + CBO + Dynamic Creative. Let Meta's AI optimize. Only segment audiences manually when you have 50+ conversions/week per segment.
