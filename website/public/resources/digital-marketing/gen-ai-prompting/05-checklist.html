AI Prompting Checklist

Before generating: ensure your prompt is structured for maximum quality output

Before You Prompt

  • □Clear objective defined — what exactly do I need?
  • □Right model selected — GPT-4o for general, Claude for writing, Gemini for long docs
  • □Context provided — background info, audience, constraints
  • □Format specified — bullet points, table, code, markdown, JSON
  • □Examples included if format is complex (few-shot)
  • □Length constraints stated — word count, character limit
  • □Tone and style defined — professional, casual, technical, persuasive
  • □Persona assigned — "Act as a senior developer/marketer/writer"

Quality Check (After Generation)

  • □Accuracy verified — facts checked against known data
  • □No hallucinations — fabricated statistics, URLs, or names
  • □Tone matches target audience
  • □Format follows specifications
  • □Actionable — can I actually use this output?
  • □Original — not generic filler content
  • □Covers all requirements from the prompt
  • □No sensitive information leaked in prompt

Prompt Library Setup

  • □Created personal prompt library (Notion/Obsidian/Google Doc)
  • □Organized by use case: writing, analysis, code, research
  • □Each prompt tested with 3 different inputs
  • □Variable placeholders marked with [brackets]
  • □Performance rated (1-5) for each prompt
  • □Version history maintained for iterations
  • □Shared with team members for collective improvement
  • □Updated monthly based on new model capabilities

Ethical Use

  • □AI-generated content disclosed where required
  • □No plagiarism — AI output used as starting point, not final
  • □Personal data not included in prompts
  • □Copyrighted material not fed into prompts
  • □Output reviewed for bias and fairness
  • □Misinformation not intentionally created
  • □AI used to augment, not replace, critical thinking

💡 Pro Tip

The best AI users aren't the ones with the fanciest prompts — they're the ones who verify outputs. Always fact-check critical information, especially for client work, publications, or decisions.
