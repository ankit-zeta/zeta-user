Learning Resources

The best free and paid platforms to learn web development

Documentation & References

MDN Web Docs
developer.mozilla.org
The definitive reference for HTML, CSS, and JavaScript. Tutorials, guides, and documentation for everything web.
Free
W3Schools
w3schools.com
Beginner-friendly tutorials with "Try it Yourself" editors. Great for quick syntax references.
Free
Can I Use
caniuse.com
Check browser support for HTML, CSS, and JS features before using them.
Free

Interactive Learning Platforms

freeCodeCamp
freecodecamp.org
Complete curriculum from HTML basics to full-stack development. Earn certifications by building projects. 100% free.
Free
Codecademy
codecademy.com
Interactive coding lessons with instant feedback. Free tier available. Pro version has projects and certificates.
Free Tier
The Odin Project
theodinproject.com
Full-stack curriculum using HTML, CSS, JavaScript, and Ruby/Node.js. Project-based, community-driven.
Free
Scrimba
scrimba.com
Interactive video courses where you can edit the code directly in the video player. Excellent for visual learners.
Free Tier

Code Editor & Tools

Visual Studio Code
code.visualstudio.com
The most popular code editor. Free, open-source, with thousands of extensions.
Free
VS Code Extensions Guide
Marketplace: search "HTML", "CSS", "JavaScript"
Top picks: Live Server, Prettier, ESLint, Auto Rename Tag, Path Intellisense, Bracket Pair Colorizer.
Free

Version Control & Hosting

GitHub Learning Lab
lab.github.com
Interactive courses on Git and GitHub. Learn branching, pull requests, and collaboration.
Free
GitHub Pages
pages.github.com
Free hosting for static websites directly from your GitHub repository. Great for portfolios.
Free
Netlify
netlify.com
Free static hosting with automatic deployments, custom domains, and SSL certificates.
Free Tier

YouTube Channels

Traversy Media
youtube.com/traversymedia
Crash courses and project tutorials on HTML, CSS, JavaScript, and frameworks.
Free
Fireship
youtube.com/fireship
Short, intense coding tutorials and technology explainers. "X in 100 seconds" series.
Free
Web Dev Simplified
youtube.com/webdevsimplified
Clear, concise tutorials on web development fundamentals and modern frameworks.
Free

💡 Recommended Learning Path

1. Start with freeCodeCamp or The Odin Project for structured learning
2. Use MDN Web Docs as your reference when you need details
3. Watch YouTube tutorials for visual explanations
4. Build projects immediately — don't just watch tutorials
5. Practice daily, even if just 30 minutes
