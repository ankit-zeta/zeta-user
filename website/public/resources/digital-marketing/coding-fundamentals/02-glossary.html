Programming Glossary

100+ essential programming and web development terms

A

  • API (Application Programming Interface)
    A set of rules that allows different software applications to communicate with each other.
  • Array
    An ordered collection of values, each accessed by an index number.
  • Async / Asynchronous
    Code that runs without blocking other operations, allowing tasks to complete in the background.
  • Attribute
    Additional information added to HTML tags, like class, id, src, or href.

B

  • Boolean
    A data type that is either true or false.
  • Bootstrap
    A popular CSS framework for building responsive websites quickly.
  • Breakpoint
    A CSS viewport width where the layout changes for different screen sizes.
  • Browser
    Software used to access and display websites (Chrome, Firefox, Safari, Edge).

C

  • Callback
    A function passed as an argument to another function, executed later.
  • CDN (Content Delivery Network)
    A distributed network of servers that delivers web content based on user location.
  • Class
    A reusable set of properties and methods; in CSS, a selector for styling elements.
  • Closure
    A function that retains access to its outer scope's variables even after the outer function returns.
  • CSS (Cascading Style Sheets)
    A language for describing the visual presentation of HTML documents.

D

  • Debugging
    The process of finding and fixing errors (bugs) in code.
  • Deployment
    The process of making a website or app available for public access on a server.
  • DOM (Document Object Model)
    A programming interface representing the structure of an HTML document as a tree of objects.

E

  • Event
    An action detected by the browser (click, scroll, keypress, form submit).
  • ES6+ (ECMAScript 2015+)
    Modern JavaScript features including arrow functions, const/let, template literals, and modules.

F

  • Framework
    A pre-built collection of code providing structure and tools (React, Vue, Angular, Django).
  • Function
    A reusable block of code that performs a specific task and can accept inputs (parameters).

G - H

  • Git
    A distributed version control system for tracking changes in source code.
  • GitHub
    A platform for hosting Git repositories with collaboration features.
  • HTML (HyperText Markup Language)
    The standard language for creating the structure of web pages.

I - J

  • IDE (Integrated Development Environment)
    A software application for writing, testing, and debugging code (VS Code, IntelliJ).
  • JSON (JavaScript Object Notation)
    A lightweight data interchange format, commonly used for API responses.

L - M

  • Library
    A collection of pre-written code for specific tasks (jQuery, Lodash, Chart.js).
  • Loop
    A control structure that repeats code blocks (for, while, for...of).
  • Method
    A function associated with an object or class.
  • Module
    A self-contained piece of JavaScript code that can be imported and exported between files.

N - P

  • Node.js
    A JavaScript runtime that allows running JavaScript outside the browser (server-side).
  • npm (Node Package Manager)
    A package manager for installing and managing JavaScript libraries.
  • Object
    A collection of key-value pairs representing an entity with properties.
  • Parameter / Argument
    A variable in a function definition (parameter) vs the actual value passed (argument).
  • Promise
    An object representing the eventual completion or failure of an asynchronous operation.

R - S

  • Repository (Repo)
    A storage location for a project's files and their version history.
  • Responsive Design
    Web design that adapts layout and content to fit different screen sizes.
  • Scope
    The accessibility of variables — global scope vs local (function) scope.
  • Semantic HTML
    Using HTML tags that describe their meaning (header, nav, article, footer).
  • String
    A sequence of characters enclosed in quotes.

T - Z

  • Terminal / Command Line
    A text-based interface for interacting with your computer and running commands.
  • Variable
    A named container for storing data values that can change during execution.
  • Viewport
    The visible area of a web page in the browser window.
  • VS Code (Visual Studio Code)
    A free, popular code editor by Microsoft with extensive extension support.

💡 Quick Tip

Keep this glossary open while you code. When you encounter an unfamiliar term, look it up here first. Repetition is the fastest way to learn technical vocabulary.
